## 1. Обзор и ключевые особенности

- **Двусторонний перевод чата в реальном времени:**
  - **Входящие сообщения:** Автоматически определяет язык союзников, переводит сообщения на выбранный вами целевой язык (поддерживает до 28 языков, включая русский, английский, испанский, португальский PT-BR, китайский, японский, французский, немецкий и многие другие) и отображает их **локально** во внутриигровом чате, **сохраняя исходное имя игрока и цветовой код** (P1 — золотой, P2 — синий, P3 — фиолетовый, P4 — бирюзовый).
  - **Исходящие сообщения:** Введите `[целевой_язык]>>сообщение` или просто `>>сообщение`, чтобы автоматически ответить на языке последнего входящего сообщения союзника. Переведенный текст отправляется по многопользовательскому RPC, поэтому иностранные напарники читают его на своем родном языке.
- **Постоянный журнал чата и экспорт в файл:** Полная история чата сессии с отметками времени, именами игроков, цветами, распознанными языками оригинала и задержкой перевода. Журнал сохраняется в таблице между перезапусками приложения благодаря легковесной асинхронной пакетной записи на диск (настраивается), с возможностью экспорта в `.txt` в один клик.
- **Поиск по журналу чата:** Полнофункциональный поиск по всей истории чата с фильтрацией по любым столбцам.

![Helldivers 1 Babel в действии](screenshots/screenshot.png)

- **Тактический быстрый чат (10 слотов):** 10 настраиваемых слотов для предустановленных тактических сообщений, привязанных к пользовательским горячим клавишам (например, Numpad 0–9 или любые комбинации), для мгновенной отправки тактических команд в игровой многопользовательский чат.
- **Автоприветствие в быстром чате:** Автоматически отправляет настраиваемое приветственное сообщение во внутриигровой чат, когда вы являетесь хостом лобби и к вам присоединяется игрок.

![Быстрый чат](screenshots/quick-chat.png)

- **Экранный оверлей-памятка быстрого чата:** Переключение плавающего ненавязчивого оверлея в правой части экрана нажатием `Numpad +` (или вашей горячей клавиши) для быстрого просмотра всех активных тактических команд и горячих клавиш прямо во время игры. *(Требуется, чтобы игра Helldivers была запущена в режиме «В окне без рамки» или «В окне»).*

![Оверлей быстрого чата](screenshots/overlay.png)

- **Поддержка 28 языков интерфейса:** Полная поддержка интерфейса на 28 языках.
- **Модульная архитектура адаптеров провайдеров:** Построена на основе расширяемого интерфейса ИИ-провайдеров. Включает оптимизированный адаптер с нулевым размышлением для **Google Gemini** (`gemini-flash-lite-latest` / `gemini-2.0-flash-lite`), а также расширяемые контракты для OpenAI, Claude и DeepSeek (в разработке).
- **Настройка стиля перевода:** Разговорный (неформальный игровой сленг и тактическая терминология) / Обычный (естественный повседневный тон общения без игрового сленга).
- **Глобальная горячая клавиша Паузы / Возобновления:** Нажмите `Ctrl + F10` (или настроенную вами комбинацию) в любое время для переключения ассистента между статусами **Активен** и **Пауза**. Пауза корректно приостанавливает как перевод внутриигрового чата, так и отправку сообщений быстрого чата.
- **Выделенные горячие клавиши для отдельных функций:**
  - **Переключение только перевода:** Нажмите `Ctrl + F11` (или вашу комбинацию) для мгновенной приостановки или возобновления перевода чата без влияния на быстрый чат (со всплывающим экранным уведомлением).
  - **Переключение только быстрого чата:** Нажмите `Ctrl + F12` (или вашу комбинацию) для мгновенной приостановки или возобновления команд быстрого чата без влияния на перевод (со всплывающим экранным уведомлением).

![Настройки](screenshots/settings.png)

- **Безопасное хранение учетных данных (DPAPI):** Конфиденциальные параметры, такие как API-ключи ИИ-провайдеров, шифруются при хранении с использованием Windows Data Protection API (DPAPI, область `CurrentUser`). Учетные данные никогда не сохраняются в виде открытого текста в конфигурационных файлах и могут быть расшифрованы только на вашем локальном компьютере под вашей учетной записью Windows.
- **Полное отсутствие телеметрии и абсолютная приватность:** Программа не собирает, не регистрирует и не отправляет пользовательские данные или данные телеметрии. Все запросы на перевод отправляются напрямую и исключительно на сервер настроенного вами ИИ-провайдера с использованием вашего личного API-ключа.
- **100% неинвазивность (без изменения файлов игры):** Игровые архивы не распаковываются и не модифицируются. Файлы вашей игры остаются на 100% чистыми и нетронутыми.

## 2. Установка и настройка

### Требования
Если вы запускаете скомпилированный автономный релиз (`HD1-Babel.exe`):
- **Операционная система:** Windows 10 / 11 64-бит (x64).
- **Среда выполнения:** [Microsoft .NET 10 Desktop Runtime (x64)](https://aka.ms/dotnet/10.0/windowsdesktop-runtime-win-x64.exe) (прямой установщик).
- **Целевая игра:** *Helldivers* (2015) в Steam (64-битный `helldivers.exe`).

### Настройка бесплатного API-ключа ИИ
- **Учетные данные ИИ-провайдера:** API-ключ Google Gemini (получите бесплатный персональный ключ в [Google AI Studio](https://aistudio.google.com/) ([Смотрите это обучающее видео](https://www.youtube.com/watch?v=YHFMrZD-_3g))).
- **Доступ в интернет:** Требуется для запросов к API перевода.

### Загрузка и установка (Готовая сборка)

Вам **не** нужно устанавливать инструменты разработчика или компилировать исходный код для использования Babel ([но если вы хотите](#4-разработка-сборка-из-исходного-кода)):
1. Перейдите в раздел **[Releases](https://github.com/difinim/helldivers1-babel/releases)** в правой части страницы проекта на GitHub.
2. Под последним релизом разверните список **Assets**.
3. Скачайте автономный архив дистрибутива: **`Helldivers1Babel-v<version>-win-x64.zip`**.
4. Распакуйте zip-архив в любое место на вашем компьютере (например, `C:\GamesTools\Helldivers1Babel`).
5. Откройте папку и запустите **`HD1-Babel.exe`**.

> [!NOTE]
> **Предварительное требование:** Конечным пользователям требуется только бесплатный [Microsoft .NET 10 Desktop Runtime (x64)](https://dotnet.microsoft.com/download/dotnet/10.0). Для запуска релиза не требуются компилятор C++, SDK или другие средства разработки.

> [!NOTE]
> **Обратите внимание**: Поскольку `InjectorService.cs` использует стандартные API внедрения процессов Windows (`VirtualAllocEx` + `WriteProcessMemory` + `CreateRemoteThread`), Защитник Windows или сторонний антивирус _**могут**_ выдать эвристическое срабатывание (например, Generic HackTool). Это нормальное поведение для инжекторов игровых модов; файл можно безопасно добавить в список исключений.

## 3. Руководство пользователя

### Начало работы
1. Запустите **Helldivers 1 Babel** (`HD1-Babel.exe`).
2. При первом запуске перейдите на вкладку **Настройки**:
   - Введите ваш **API-ключ Google Gemini** (безопасно сохраняется с шифрованием Windows DPAPI).
   - Выберите ваш целевой язык (например, `Русский`).
   - Нажмите **Проверить API-соединение**, чтобы проверить ключ и задержку.
   - При желании настройте горячую клавишу **Пауза/Возобновление** (по умолчанию `Ctrl + F10`).
3. Настройте тактические команды на вкладке **Быстрый чат** (например, назначьте Numpad 0–9 на нужные сообщения).
4. Запустите **Helldivers** в Steam. Babel автоматически обнаружит процесс `helldivers.exe`, внедрит `BabelHook.dll` и установит высокоскоростное IPC-соединение через именованный канал.

### Общение в игре и сценарии использования

#### 1. Автоматический входящий перевод
Входящие сообщения союзников распознаются и переводятся на ваш целевой язык на лету, отображаясь во внутриигровом чате с сохранением исходного имени игрока и его цвета:
- Союзник (English): `so quiet`
- Внутриигровой чат: `Diveheller: (English): так тихо`

#### 2. Автоответ на языке последнего входящего сообщения (`>>сообщение`)
Если добавить перед сообщением префикс `>>`, текст будет автоматически переведен на язык последнего входящего сообщения напарника:
- Ваш ввод в чате: `>>да, слишком тихо`
- Союзник видит: `yes, it is too quiet`

#### 3. Явный выбор произвольного языка (`целевой язык>>сообщение`)
Отправляйте сообщение на конкретном языке в любое время, указав название языка перед префиксом `>>`:

| Команда ввода в чат | Целевой язык | Пример результата, передаваемого союзникам |
| :--- | :--- | :--- |
| `russian>>bom dia!` | Русский | `доброе утро!` |
| `english>>мины на севере` | Английский | `mines to the north` |
| `japanese>>берегитесь огня!` | Японский | `射線に注意せよ！` |
| `spanish>>нужны патроны` | Испанский | `necesito munición` |
| `german>>отступаем к точке эвакуации` | Немецкий | `Rückzug zum Extraktionspunkt` |
| `french>>держим оборону здесь` | Французский | `défendons cette position` |

#### 4. Стандартные исходящие сообщения и подавление самоперевода
Когда вы вводите обычное сообщение в чат игры без префикса `>>` (например, `need ammo`, `погнали`), оно передается напрямую через стандартный многопользовательский чат. При включенной опции **«Не переводить стандартные исходящие»** (по умолчанию включена на панели быстрого управления и в Настройках), Babel подавляет обратный перевод вашего собственного сообщения вам же. Если опцию выключить, Babel будет также обрабатывать локальные исходящие сообщения через цепочку входящего перевода.

#### 5. Горячие клавиши тактического быстрого чата
Нажимайте любую настроенную горячую клавишу быстрого чата (например, `NumPad 1`–`NumPad 9`) во время игры, чтобы мгновенно передавать предустановленные команды в командный чат без открытия окна ввода. Все нажатия клавиш прозрачно передаются в игру, поэтому управление остается полностью отзывчивым.

#### 6. Экранный оверлей-памятка быстрого чата (`Numpad +`)
Нажмите `Numpad +` (или настроенную вами комбинацию клавиш на вкладке **Быстрый чат**) в любое время, чтобы отобразить или скрыть экранный оверлей со списком всех активных слотов быстрого чата. Оверлей отображается справа по центру экрана по вертикали, показывая каждый активный слот в формате `[<клавиша>] <сообщение>` (сообщения укорачиваются до 30 символов) в едином аккуратном визуальном стиле с уведомлениями.
> [!NOTE]
> **Требования к режиму отображения:** В настройках графики Helldivers игра должна быть переведена в режим **«В окне без рамки»** (Borderless Fullscreen) или **«В окне»** (Windowed), чтобы оверлеи Windows могли отображаться поверх игры.

#### 7. Пауза, возобновление и раздельное управление функциями
- **Глобальная Пауза / Возобновление (`Ctrl + F10`):** Главный переключатель, который одновременно приостанавливает или возобновляет как перехват перевода, так и трансляцию сообщений быстрого чата.
- **Вкл/выкл только перевода (`Ctrl + F11`):** Включает или выключает только функцию перевода чата со всплывающим экранным уведомлением. Быстрый чат продолжает работать штатно.
- **Вкл/выкл только быстрого чата (`Ctrl + F12`):** Включает или выключает только трансляцию сообщений быстрого чата со всплывающим экранным уведомлением. Перевод внутриигрового чата продолжает работать штатно.
*(Все сочетания клавиш можно настроить на вкладках **Настройки** и **Быстрый чат**, просто нажав нужные кнопки).*

#### 8. Экспорт и постоянный журнал чата
Нажмите **Экспорт журнала** на вкладке «Перевод и Журнал» в любое время, чтобы выбрать папку и сохранить историю чата (с отметками времени, именами игроков, оригинальными сообщениями, переводами и задержкой) в файл `.txt`. Сообщения чата автоматически сохраняются в таблице между запусками приложения за счет асинхронной пакетной записи на диск (лимит настраивается от 0 до 100 МБ в Настройках, доступна кнопка **Очистить память логов**).

#### 9. Интерактивные ссылки в сообщениях
Сообщения чата отряда, содержащие ссылки `http://` или `https://`, отображаются как кликабельные ссылки в столбце **Оригинал**. При нажатии на ссылку появляется диалоговое окно подтверждения, предлагающее подтвердить надежность ссылки перед ее открытием в системном веб-браузере по умолчанию.

## 4. Разработка (Сборка из исходного кода)

### Требования для разработчиков
Если вы компилируете и собираете проект из исходного кода:
- **Операционная система:** Windows 10 / 11 64-бит (x64).
- **.NET 10 SDK:** [.NET 10 SDK](https://dotnet.microsoft.com/download/dotnet/10.0) (`net10.0-windows`).
- **Инструменты MSYS2 MinGW64 (Clang++, GCC, Make):** [MSYS2](https://www.msys2.org/) с пакетами `mingw-w64-x86_64-clang`, `mingw-w64-x86_64-gcc` и `mingw-w64-x86_64-make` — требуются для компиляции нативной библиотеки перехвата (`BabelHook.dll`) и сборки официального подмодуля LuaJIT 2.0 (`vendor/luajit`) для компиляции загрузочного скрипта (`babel_bootstrap.lua`) в байт-код.
- **Git:** Git для Windows (с рекурсивными подмодулями для MinHook amalgamation и LuaJIT 2.0).

### Автоматическая настройка окружения
Запустите `setup.bat` двойным кликом (или выполните `setup.ps1` в PowerShell) в корневой папке репозитория. Скрипт автоматически проверит и установит недостающие компоненты:
1. Проверяет 64-битное окружение Windows.
2. Проверяет наличие .NET 10 SDK (автоматически устанавливает через `winget`, если отсутствует).
3. Проверяет наличие инструментов MSYS2 MinGW64 (Clang++, GCC и Make). Если они не найдены, автоматически устанавливает MSYS2 через `winget` и необходимые пакеты (`mingw-w64-x86_64-clang`, `mingw-w64-x86_64-gcc` и `mingw-w64-x86_64-make`) через `pacman`.
4. Инициализирует и собирает компилятор LuaJIT 2.0 из подмодуля (`vendor/luajit`).
5. Автоматически проверяет добавление путей `C:\msys64\mingw64\bin` и `C:\msys64\usr\bin` в переменную среды PATH.
6. Проверяет зависимости MinHook amalgamation и выполняет базовую проверку сборки.

### Основная сборка и создание пакета релиза
Чтобы очистить предыдущие артефакты, скомпилировать нативную библиотеку перехвата, запустить все модульные тесты и собрать пакет релиза:
```powershell
pwsh -File build.ps1
```
Файлы релиза будут собраны в папку `dist/Helldivers1Babel-vX.Y.Z/`.

### Пошаговая ручная сборка
```powershell
# 1. Сборка нативной библиотеки хука (автоматически компилирует babel_bootstrap.lua с помощью luajit)
pwsh -File src/Babel.Hook/build.ps1

# 2. Сборка решения .NET 10
dotnet build Helldivers1Babel.slnx

# 3. Запуск автоматических тестов
dotnet test
```
