## 1. Огляд та ключові особливості

- **Двосторонній переклад чату в реальному часі:**
  - **Вхідні повідомлення:** Автоматично розпізнає мову союзників, перекладає повідомлення вашою обраною цільовою мовою (підтримує до 28 цільових мов, включаючи українську, португальську PT-BR, англійську, іспанську, російську, китайську, японську, французьку, німецьку та інші) та відображає їх **локально** у внутрішньоігровому чаті, **зберігаючи оригінальне ім'я гравця та колірний код** (P1 — золотий, P2 — синій, P3 — фіолетовий, P4 — бірюзовий).
  - **Вихідні повідомлення:** Введіть `[цільова_мова]>>повідомлення` або просто `>>повідомлення`, щоб автоматично відповісти мовою останнього вхідного повідомлення союзника. Перекладений текст транслюється через мережевий RPC, тому іноземні напарники читають його рідною мовою.
- **Незмінні журнали чату та експорт у файл:** Повне відстеження історії чату сесії з часовими мітками, іменами гравців, кольорами, розпізнаними мовами оригіналу та затримкою перекладу. Журнали зберігаються в таблиці між перезапусками програми завдяки легковажному асинхронному пакетному запису на диск (налаштовується), з можливістю експорту у файл `.txt` в один клік.
- **Пошук у журналах чату:** Повнофункціональний пошук по всій історії чату з фільтрацією за будь-яким стовпцем.

![Helldivers 1 Babel у дії](screenshots/screenshot.png)

- **Тактичний швидкий чат (10 слотів):** 10 настроюваних слотів для попередньо визначених тактичних повідомлень, прив'язаних до користувацьких гарячих клавіш (наприклад, Numpad 0–9 або довільні комбінації), для миттєвої відправки тактичних викликів у багатокористувацький ігровий чат.

![Швидкий чат](screenshots/quick-chat.png)

- **Автопривітання швидкого чату:** Автоматично надсилає настроюване вітальне повідомлення в ігровий чат, коли ви хостуєте лобі та до гри приєднується інший гравець.
- **Екранний оверлей-довідник швидкого чату:** Увімкнення плаваючого ненав'язливого оверлею у правій частині екрана натисканням `Numpad +` (або власної гарячої клавіші) для швидкого перегляду всіх активних тактичних команд і клавіш безпосередньо під час гри. *(Потрібно, щоб Helldivers була запущена в режимі «Безрамкове вікно» або «У вікні»).*

![Оверлей швидкого чату](screenshots/overlay.png)

- **Підтримка 28 мов інтерфейсу:** Повний переклад інтерфейсу користувача 28 мовами.
- **Модульна архітектура адаптерів провайдерів:** Створена на основі модульного інтерфейсу ШІ-провайдерів. Містить оптимізований адаптер без затримок міркування для **Google Gemini** (`gemini-flash-lite-latest` / `gemini-2.0-flash-lite`), а також розширювані контракти для OpenAI, Claude та DeepSeek (у розробці).
- **Налаштування стилю перекладу:** Розмовний (неформальний ігровий сленг і тактичний жаргон) / Звичайний (природний повсякденний стиль спілкування без специфічного сленгу).
- **Глобальна гаряча клавіша Паузи / Відновлення:** Натисніть `Ctrl + F10` (або налаштовану комбінацію) будь-коли, щоб перемкнути помічника між станами **Активний** та **Пауза**. Пауза акуратно призупиняє як переклад чату гри, так і надсилання повідомлень швидкого чату.
- **Окремі гарячі клавіші функцій:**
  - **Перемикання лише перекладу:** Натисніть `Ctrl + F11` (або власну комбінацію), щоб миттєво призупинити чи відновити переклад чату без впливу на швидкий чат (зі сповіщенням на екрані).
  - **Перемикання лише швидкого чату:** Натисніть `Ctrl + F12` (або власну комбінацію), щоб миттєво призупинити чи відновити швидкий чат без впливу на переклад (зі сповіщенням на екрані).

![Налаштування](screenshots/settings.png)

- **Безпечне збереження облікових даних (DPAPI):** Чутливі параметри, такі як API-ключі ШІ-провайдерів, шифруються на диску за допомогою Windows Data Protection API (DPAPI, область `CurrentUser`). Ключі ніколи не зберігаються відкритим текстом у файлах конфігурації та можуть бути розшифровані лише на вашому комп'ютері під вашим обліковим записом Windows.
- **Повна відсутність телеметрії та абсолютна конфіденційність:** Програма не збирає, не реєструє та не надсилає жодних даних користувача чи телеметрії. Усі запити на переклад надсилаються безпосередньо та виключно на кінцеву точку вашого налаштованого ШІ-провайдера з використанням особистого API-ключа.
- **100% неінвазивність (без модифікації файлів гри):** Архіви гри не розпаковуються і не модифікуються. Файли гри залишаються повністю чистими та незмінними.

## 2. Встановлення та налаштування

### Вимоги
Якщо ви використовуєте попередньо скомпільовану автономну версію (`HD1-Babel.exe`):
- **Операційна система:** Windows 10 / 11 64-біт (x64).
- **Середовище виконання:** [Microsoft .NET 10 Desktop Runtime (x64)](https://aka.ms/dotnet/10.0/windowsdesktop-runtime-win-x64.exe) (прямий установник).
- **Цільова гра:** *Helldivers* (2015) у Steam (64-бітний `helldivers.exe`).

### Налаштування безкоштовного API-ключа ШІ
- **Облікові дані ШІ-провайдера:** API-ключ Google Gemini (отримайте безкоштовний персональний ключ у [Google AI Studio](https://aistudio.google.com/) ([Дивіться навчальне відео](https://www.youtube.com/watch?v=YHFMrZD-_3g))).
- **Доступ до інтернету:** Потрібен для виконання запитів до API перекладу.

### Завантаження та встановлення (Готова збірка)

Вам **не** потрібно встановлювати інструменти розробника або компілювати код із джерел, щоб користуватися Babel ([якщо тільки ви самі цього не бажаєте](#4-розробка-збірка-з-вихідного-коду)):
1. Перейдіть до розділу **[Releases](https://github.com/difinim/helldivers1-babel/releases)** у правій частині сторінки проєкту на GitHub.
2. Під останнім релізом розгорніть список **Assets**.
3. Завантажте архів дистрибутива: **`Helldivers1Babel-v<version>-win-x64.zip`**.
4. Розархівуйте zip-файл у будь-яку папку на комп'ютері (наприклад, `C:\GamesTools\Helldivers1Babel`).
5. Відкрийте папку та запустіть **`HD1-Babel.exe`**.

> [!NOTE]
> **Попередня вимога:** Кінцевим користувачам потрібен лише безкоштовний [Microsoft .NET 10 Desktop Runtime (x64)](https://dotnet.microsoft.com/download/dotnet/10.0). Для роботи збірки не потрібні компілятори C++, SDK чи інші інструменти складання.

> [!NOTE]
> **Зверніть увагу**: Оскільки `InjectorService.cs` використовує стандартні API Windows для ін'єкції у процеси (`VirtualAllocEx` + `WriteProcessMemory` + `CreateRemoteThread`), Windows Defender або сторонній антивірус _**можуть**_ видати евристичне попередження (наприклад, Generic HackTool). Це звична поведінка для інжекторів модифікацій; файл можна безпечно додати до списку виключень.

## 3. Посібник користувача

### Початок роботи
1. Запустіть **Helldivers 1 Babel** (`HD1-Babel.exe`).
2. Під час першого запуску відкрийте вкладку **Налаштування**:
   - Введіть свій **API-ключ Google Gemini** (безпечно зберігається із шифруванням Windows DPAPI).
   - Оберіть цільову мову (наприклад, `Українська`).
   - Натисніть **Перевірити підключення API**, щоб перевірити ключ та затримку.
   - За бажанням змініть комбінацію клавіш **Пауза/Відновлення** (типово `Ctrl + F10`).
3. Налаштуйте тактичні команди на вкладці **Швидкий чат** (наприклад, прив'яжіть Numpad 0–9 до бажаних повідомлень).
4. Запустіть **Helldivers** у Steam. Babel автоматично виявить `helldivers.exe`, інжектує бібліотеку `BabelHook.dll` і встановить високошвидкісне IPC-з'єднання через іменований канал.

### Спілкування у грі та сценарії використання

#### 1. Автоматичний вхідний переклад
Вхідні повідомлення напарників автоматично виявляються та перекладаються обраною цільовою мовою на льоту, з'являючись у чаті гри зі збереженням імені гравця та його кольору:
- Напарник (English): `so quiet`
- Ігровий чат: `Diveheller: (English): так тихо`

#### 2. Автовідповідь мовою останнього вхідного повідомлення (`>>повідомлення`)
Префікс `>>` перед повідомленням автоматично перекладає ваш текст мовою останнього отриманого повідомлення союзника:
- Ваш ввід у чаті: `>>так, занадто тихо`
- Союзник бачить: `yes, it is too quiet`

#### 3. Явний вибір довільної мови (`цільова мова>>повідомлення`)
Надсилайте повідомлення конкретною мовою у будь-який час, додавши назву мови перед `>>`:

| Команда введення в чат | Цільова мова | Приклад результату, трансльованого напарникам |
| :--- | :--- | :--- |
| `russian>>bom dia!` | Російська | `доброе утро!` |
| `english>>міни на півночі` | Англійська | `mines to the north` |
| `japanese>>обережно з вогнем!` | Японська | `射線に注意せよ！` |
| `spanish>>потрібні набої` | Іспанська | `necesito munición` |
| `german>>відступаємо до точки евакуації` | Німецька | `Rückzug zum Extraktionspunkt` |
| `french>>тримаємо оборону тут` | Французька | `défendons cette position` |

#### 4. Стандартні вихідні повідомлення та придушення самоперекладу
Коли ви вводите звичайне повідомлення в ігровий чат без префікса `>>` (наприклад, `need ammo`, `вперед`), воно надсилається безпосередньо через стандартний багатокористувацький чат. Якщо опція **«Не перекладати звичайні вихідні»** увімкнена (активна за замовчуванням на панелі швидкого керування та в Налаштуваннях), Babel придушує повторний переклад вашого власного повідомлення вам же. Якщо її вимкнути, Babel спрямовуватиме вихідні повідомлення через ланцюжок вхідного перекладу.

#### 5. Гарячі клавіші тактичного швидкого чату
Натискайте будь-яку налаштовану гарячу клавішу швидкого чату (наприклад, `NumPad 1`–`NumPad 9`) під час гри, щоб миттєво транслювати готові повідомлення в командний чат без відкриття рядка вводу. Усі натискання клавіш безперешкодно проходять у гру, тому керування залишається максимально чутливим.

#### 6. Екранний оверлей-довідник швидкого чату (`Numpad +`)
Натисніть `Numpad +` (або вашу комбінацію клавіш, налаштовану на вкладці **Швидкий чат**) будь-коли, щоб показати або сховати екранний оверлей з усіма активними командами швидкого чату. Оверлей з'являється праворуч по центру екрана по вертикалі, показуючи кожен активний слот у форматі `[<клавіша>] <повідомлення>` (довжина тексту обмежується 30 символами) у ненав'язливому стилі екранних сповіщень.
> [!NOTE]
> **Вимога до режиму відображення:** У відеопараметрах Helldivers слід обрати режим **«Безрамкове вікно»** (Borderless Fullscreen) або **«У вікні»** (Windowed), щоб оверлеї Windows могли відображатися поверх гри.

#### 7. Пауза, відновлення та роздільне керування функціями
- **Глобальна Пауза / Відновлення (`Ctrl + F10`):** Головний вимикач, що одночасно призупиняє або відновлює як перехоплення перекладу, так і надсилання повідомлень швидкого чату.
- **Увімк/Вимк лише переклад (`Ctrl + F11`):** Вмикає або вимикає виключно переклад чату зі спливаючим екранним сповіщенням. Швидкий чат продовжує працювати без змін.
- **Увімк/Вимк лише швидкий чат (`Ctrl + F12`):** Вмикає або вимикає виключно надсилання тактичних повідомлень швидкого чату зі спливаючим екранним сповіщенням. Переклад чату гри продовжує працювати без змін.
*(Усі комбінації клавіш можна змінити на вкладках **Налаштування** та **Швидкий чат** за допомогою кнопок запису натискань).*

#### 8. Експорт та збереження журналів чату
Натисніть **Експорт журналу** на вкладці «Переклад і Журнал» у будь-який час, щоб зберегти історію чату (з мітками часу, іменами гравців, оригінальними повідомленнями, перекладами та затримками) у файл `.txt`. Повідомлення чату автоматично зберігаються в таблиці між запусками програми за допомогою асинхронного пакетного запису на диск (ліміт пам'яті налаштовується від 0 до 100 МБ у Налаштуваннях, доступна кнопка **Очистити пам'ять логів**).

#### 9. Інтерактивні посилання в повідомленнях
Повідомлення чату загону, що містять URL-адреси `http://` або `https://`, відображаються як інтерактивні посилання в стовпці **Оригінал**. При натисканні на посилання з'являється діалогове вікно підтвердження безпеки перед відкриттям адреси у вашому браузері за замовчуванням.

## 4. Розробка (Збірка з вихідного коду)

### Вимоги для розробників
Якщо ви компілюєте та збираєте проєкт із вихідного коду:
- **Операційна система:** Windows 10 / 11 64-біт (x64).
- **.NET 10 SDK:** [.NET 10 SDK](https://dotnet.microsoft.com/download/dotnet/10.0) (`net10.0-windows`).
- **Набір інструментів MSYS2 MinGW64 (Clang++, GCC, Make):** [MSYS2](https://www.msys2.org/) з пакетами `mingw-w64-x86_64-clang`, `mingw-w64-x86_64-gcc` та `mingw-w64-x86_64-make` — необхідні для компіляції нативної бібліотеки перехоплення (`BabelHook.dll`) та збірки офіційного підмодуля LuaJIT 2.0 (`vendor/luajit`) для компіляції завантажувального скрипта (`babel_bootstrap.lua`) у байт-код.
- **Git:** Git для Windows (з рекурсивними підмодулями для MinHook amalgamation та LuaJIT 2.0).

### Автоматизоване налаштування середовища
Запустіть `setup.bat` подвійним кліком (або виконайте `setup.ps1` у PowerShell) у корені репозиторію. Скрипт автоматично перевірить та встановить необхідні компоненти:
1. Перевіряє 64-бітне середовище Windows.
2. Перевіряє наявність .NET 10 SDK (автоматично встановлює через `winget`, якщо відсутній).
3. Перевіряє наявність інструментів MSYS2 MinGW64 (Clang++, GCC та Make). Якщо вони відсутні, автоматично встановлює MSYS2 через `winget` та відповідні пакети (`mingw-w64-x86_64-clang`, `mingw-w64-x86_64-gcc` та `mingw-w64-x86_64-make`) через `pacman`.
4. Ініціалізує та збирає компілятор LuaJIT 2.0 з підмодуля (`vendor/luajit`).
5. Автоматично переконується, що шляхи `C:\msys64\mingw64\bin` та `C:\msys64\usr\bin` додані до змінної середовища PATH.
6. Перевіряє залежності MinHook amalgamation та виконує початкову перевірку збірки.

### Головна збірка та пакування релізу
Щоб очистити попередні артефакти, скомпілювати нативну DLL перехоплення, виконати всі модульні тести та зібрати релізний пакет:
```powershell
pwsh -File build.ps1
```
Готовий каталог буде запаковано до `dist/Helldivers1Babel-vX.Y.Z/`.

### Покрокова ручна збірка
```powershell
# 1. Збірка нативної бібліотеки хука (автоматично компілює babel_bootstrap.lua за допомогою luajit)
pwsh -File src/Babel.Hook/build.ps1

# 2. Збірка рішення .NET 10
dotnet build Helldivers1Babel.slnx

# 3. Запуск автоматичних наборів тестів
dotnet test
```
