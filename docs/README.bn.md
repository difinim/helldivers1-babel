## ১. সংক্ষিপ্ত বিবরণ এবং মূল বৈশিষ্ট্য

- **রিয়েল-টাইম দ্বিমুখী চ্যাট অনুবাদ:**
  - **আগত বার্তা:** সতীর্থদের ভাষা স্বয়ংক্রিয়ভাবে সনাক্ত করে, বার্তাগুলিকে আপনার নির্বাচিত লক্ষ্য ভাষায় অনুবাদ করে (পর্তুগিজ PT-BR, ইংরেজি, স্প্যানিশ, রাশিয়ান, চীনা, জাপানি, ফরাসি, জার্মান সহ মোট ২৮টি লক্ষ্য ভাষা সমর্থন করে), এবং মূল খেলোয়াড়ের নাম ও রঙের কোড অক্ষুণ্ণ রেখে (P1 গোল্ড, P2 ব্লু, P3 পার্পল, P4 সায়ান) ইন-গেম চ্যাটে **স্থানীয়ভাবে** রেন্ডার করে।
  - **বহির্গামী বার্তা:** সর্বশেষ আগত সতীর্থের বার্তার ভাষায় স্বয়ংক্রিয়ভাবে উত্তর দিতে `[target_language]>>বার্তা` অথবা কেবল `>>বার্তা` টাইপ করুন। অনূদিত টেক্সট মাল্টিপ্লেয়ার RPC-এর মাধ্যমে সম্প্রচারিত হয় যাতে আন্তর্জাতিক সতীর্থরা তা তাদের নিজস্ব ভাষায় পড়তে পারেন।
- **স্থায়ী চ্যাট লগ এবং ফাইল রপ্তানি:** টাইমস্ট্যাম্প, খেলোয়াড়ের নাম, রং, সনাক্তকৃত উৎস ভাষা এবং অনুবাদের লেটেন্সি সহ সম্পূর্ণ সেশনের চ্যাট ইতিহাসের ট্র্যাকিং। লাইটওয়েট অ্যাসিঙ্ক্রোনাস ব্যাচ ডিস্ক রাইটস (কনফিগারযোগ্য)-এর মাধ্যমে অ্যাপ্লিকেশন পুনরায় চালুর পরেও লগ টেবিলে সংরক্ষিত থাকে, এবং এক ক্লিকে একটি `.txt` ফাইলে রপ্তানি করা যায়।
- **অনুসন্ধানযোগ্য চ্যাট লগ:** সম্পূর্ণ অনুসন্ধানযোগ্য চ্যাট ইতিহাস যা যেকোনো কলাম ফিল্টার করতে পারে।

![Helldivers 1 Babel কার্যক্রম](screenshots/screenshot.png)

- **কৌশলগত দ্রুত চ্যাট (১০টি কাস্টম স্লট):** ১০টি কাস্টমাইজযোগ্য প্রাক-নির্ধারিত কৌশলগত বার্তার স্লট, যার প্রতিটি ব্যবহারকারী-কনফিগারযোগ্য হটকি (যেমন Numpad 0-9 বা কাস্টম সমন্বয়)-তে যুক্ত, যাতে তাত্ক্ষণিকভাবে ইন-গেম মাল্টিপ্লেয়ার চ্যাটে কৌশলগত কলআউট পাঠানো যায়।

![দ্রুত চ্যাট](screenshots/quick-chat.png)

- **স্বয়ংক্রিয় স্বাগত দ্রুত চ্যাট বার্তা:** আপনি যখন কোনো লবি হোস্ট করেন এবং কোনো অতিথি খেলোয়াড় যোগ দেন, তখন স্বয়ংক্রিয়ভাবে ইন-গেম চ্যাটে একটি কাস্টমাইজেবল স্বাগত বার্তা সম্প্রচার করে।
- **অন-স্ক্রিন দ্রুত চ্যাট রেফারেন্স ওভারলে:** ইন-গেমে সমস্ত সক্রিয় কৌশলগত কলআউট এবং শর্টকাট দ্রুত দেখতে `Numpad +` (বা আপনার রেকর্ড করা শর্টকাট) দিয়ে স্ক্রিনের ডানদিকে একটি নন-অ্যাক্টিভেটিং ভাসমান রেফারেন্স ওভারলে টগল করুন। *(Helldivers অবশ্যই বর্ডারলেস ফুলস্ক্রিন বা উইন্ডোড মোডে চলতে হবে)*।

![দ্রুত চ্যাট ওভারলে](screenshots/overlay.png)

- **বহুভাষিক UI সমর্থন:** ২৮টি ভাষা সমর্থন করে।
- **প্রোভাইডার অ্যাডাপ্টার আর্কিটেকচার:** একটি মডুলার AI প্রোভাইডার ইন্টারফেস দিয়ে নির্মিত। **Google Gemini** (`gemini-flash-lite-latest` / `gemini-2.0-flash-lite`)-এর জন্য একটি অপ্টিমাইজড, জিরো-থিঙ্কিং অ্যাডাপ্টার সহ আসে, এবং এতে OpenAI, Claude, ও DeepSeek-এর জন্য এক্সটেনসিবল প্রোভাইডার চুক্তি অন্তর্ভুক্ত রয়েছে (এখনও বাস্তবায়িত হয়নি)।
- **অনুবাদ শৈলী সেটিংস:** ক্যাজুয়াল: অনানুষ্ঠানিক গেমিং অপভাষা ও কৌশলগত গেমার পরিভাষা / সাধারণ: গেমিং অপভাষা ছাড়া স্বাভাবিক কথোপকথন শৈলী।
- **গ্লোবাল বিরতি / পুনরায় শুরু হটকি:** সহকারীকে **সক্রিয়** এবং **বিরতিপ্রাপ্ত** অবস্থার মধ্যে পরিবর্তন করতে যেকোনো সময় `Ctrl + F10` (বা আপনার কনফিগার করা শর্টকাট) টিপুন। বিরতি দিলে ইন-গেম চ্যাট অনুবাদ এবং দ্রুত চ্যাট বার্তা সম্প্রচার উভয়ই নিখুঁতভাবে স্থগিত হয়।
- **ডেডিকেটেড ফিচার হটকি:**
  - **শুধুমাত্র অনুবাদ টগল করুন:** দ্রুত চ্যাটকে প্রভাবিত না করে তাত্ক্ষণিকভাবে চ্যাট অনুবাদ স্থগিত বা পুনরায় শুরু করতে `Ctrl + F11` (বা আপনার রেকর্ড করা শর্টকাট) টিপুন (অন-স্ক্রিন টোস্ট প্রতিক্রিয়া সহ)।
  - **শুধুমাত্র দ্রুত চ্যাট টগল করুন:** অনুবাদকে প্রভাবিত না করে তাত্ক্ষণিকভাবে দ্রুত চ্যাট কলআউট স্থগিত বা পুনরায় শুরু করতে `Ctrl + F12` (বা আপনার রেকর্ড করা শর্টকাট) টিপুন (অন-স্ক্রিন টোস্ট প্রতিক্রিয়া সহ)।

![সেটিংস](screenshots/settings.png)

- **নিরাপদ শংসাপত্র সঞ্চয়স্থান (DPAPI):** AI প্রোভাইডারের API টোকেনের মতো সংবেদনশীল পছন্দগুলি Windows Data Protection API (DPAPI, `CurrentUser` স্কোপ) ব্যবহার করে এনক্রিপ্ট করে সংরক্ষণ করা হয়। শংসাপত্রগুলি কখনই কনফিগারেশন ফাইলগুলিতে প্লেইনটেক্সট হিসেবে সংরক্ষণ করা হয় না এবং শুধুমাত্র আপনার স্থানীয় মেশিনে আপনার Windows অ্যাকাউন্ট দ্বারাই ডিক্রিপ্ট করা সম্ভব।
- **জিরো টেলিমেট্রি এবং সম্পূর্ণ গোপনীয়তা:** এই টুলটি কোনো ব্যবহারকারীর ডেটা বা টেলিমেট্রি ডেটা সংগ্রহ, লগ বা প্রেরণ করে না। সমস্ত অনুবাদের অনুরোধ আপনার ব্যক্তিগত API শংসাপত্র ব্যবহার করে সরাসরি এবং একচেটিয়াভাবে আপনার কনফিগার করা AI প্রোভাইডার এন্ডপয়েন্টের সাথে যোগাযোগ করে।
- **১০০% নন-ইনভেসিভ (গেম ফাইলে কোনো পরিবর্তন নেই):** কোনো গেম আর্কাইভ আনপ্যাক বা পরিবর্তন করা হয় না। আপনার গেম ফাইলগুলি শতভাগ ভ্যানিলা এবং অবিকৃত থাকে।




## ২. সেটআপ

### প্রয়োজনীয়তা
আপনি যদি প্রাক-সংকলিত স্ট্যান্ডঅ্যালোন রিলিজ (`HD1-Babel.exe`) চালান:
- **অপারেটিং সিস্টেম:** Windows 10 / 11 64-বিট (x64)।
- **ডেস্কটপ রানটাইম:** [Microsoft .NET 10 Desktop Runtime (x64)](https://aka.ms/dotnet/10.0/windowsdesktop-runtime-win-x64.exe) (সরাসরি ইনস্টলার)।
- **টার্গেট গেম:** Steam-এ *Helldivers* (2015) (64-বিট `helldivers.exe`)।

### একটি বিনামূল্যের AI API কী সেটআপ করুন
- **AI প্রোভাইডার শংসাপত্র:** Google Gemini API কী ([Google AI Studio](https://aistudio.google.com/) থেকে বিনামূল্যে ব্যক্তিগত কী সংগ্রহ করুন ([এই টিউটোরিয়াল ভিডিওটি দেখুন](https://www.youtube.com/watch?v=YHFMrZD-_3g)))।

### ডাউনলোড এবং ইনস্টলেশন (প্রাক-নির্মিত রিলিজ)

Babel ব্যবহার করার জন্য আপনার ডেভেলপার টুলস ইনস্টল বা সোর্স থেকে কম্পাইল করার **কোনো প্রয়োজন নেই** ([তবে আপনি যদি চান](#৪-ডেভেলপমেন্ট-সোর্স-থেকে-বিল্ড)):
1. GitHub প্রজেক্ট পৃষ্ঠার ডানদিকে **[Releases](https://github.com/difinim/helldivers1-babel/releases)** বিভাগে যান।
2. সর্বশেষ রিলিজের অধীনে **Assets** তালিকাটি প্রসারিত করুন।
3. স্ট্যান্ডঅ্যালোন ডিস্ট্রিবিউশন আর্কাইভটি ডাউনলোড করুন: **`Helldivers1Babel-v<version>-win-x64.zip`**।
4. আপনার কম্পিউটারের যেকোনো স্থানে জিপ ফাইলটি আনজিপ করুন (যেমন `C:\GamesTools\Helldivers1Babel`)।
5. ফোল্ডারটি খুলুন এবং **`HD1-Babel.exe`** চালান।

> [!NOTE]
> **পূর্বশর্ত:** সাধারণ ব্যবহারকারীদের জন্য শুধুমাত্র বিনামূল্যের [Microsoft .NET 10 Desktop Runtime (x64)](https://dotnet.microsoft.com/download/dotnet/10.0) প্রয়োজন। রিলিজ চালানোর জন্য কোনো C++ কম্পাইলার, SDK বা টুলচেইনের প্রয়োজন নেই।

> [!NOTE]
> **সচেতন থাকুন**: যেহেতু InjectorService.cs স্ট্যান্ডার্ড উইন্ডোজ প্রসেস ইনজেকশন API (`VirtualAllocEx` + `WriteProcessMemory` + `CreateRemoteThread`) ব্যবহার করে, উইন্ডোজ ডিফেন্ডার বা তৃতীয় পক্ষের অ্যান্টিভাইরাস হিউরিস্টিক সনাক্তকরণ (যেমন Generic HackTool) ট্রিগার _**করতে পারে**_। এটি গেম মড ইনজেক্টরের ক্ষেত্রে স্বাভাবিক আচরণ এবং এটিকে নিরাপদে অনুমতি তালিকায় (allowlist) যোগ করা যেতে পারে।



## ৩. ব্যবহারের নির্দেশিকা

### শুরু করা
1. **Helldivers 1 Babel** (`HD1-Babel.exe`) চালু করুন।
2. প্রথম চালনায়, **সেটিংস** ট্যাবটি খুলুন:
   - আপনার **Google Gemini API কী** লিখুন (Windows DPAPI এনক্রিপশনের মাধ্যমে নিরাপদে সংরক্ষিত)।
   - আপনার লক্ষ্য ভাষা নির্বাচন করুন (যেমন `Portuguese (PT-BR)`)।
   - আপনার কী এবং লেটেন্সি যাচাই করতে **API সংযোগ পরীক্ষা করুন**-এ ক্লিক করুন।
   - প্রয়োজনে **বিরতি/পুনরায় শুরু** শর্টকাট কাস্টমাইজ করুন (ডিফল্ট `Ctrl + F10`)।
3. **দ্রুত চ্যাট** ট্যাবে আপনার কৌশলগত কলআউটগুলি কনফিগার করুন (যেমন Numpad 0-9 কীগুলিতে আপনার পছন্দের বার্তা যুক্ত করুন)।
4. Steam-এ **Helldivers** চালু করুন। Babel স্বয়ংক্রিয়ভাবে `helldivers.exe` সনাক্ত করে, `BabelHook.dll` ইনজেক্ট করে এবং উচ্চ-গতির নেমড পাইপ IPC স্থাপন করে।

### ইন-গেম যোগাযোগ এবং ব্যবহারের ক্ষেত্র

#### ১. স্বয়ংক্রিয় আগত অনুবাদ
সতীর্থদের থেকে আগত বার্তাগুলি স্বয়ংক্রিয়ভাবে সনাক্ত হয় এবং অবিলম্বে আপনার লক্ষ্য ভাষায় অনূদিত হয়, যা ইন-গেম চ্যাটে মূল খেলোয়াড়ের নাম এবং রঙের সাথে প্রদর্শিত হয়:
- সতীর্থ (English): `so quiet`
- ইন-গেম চ্যাট: `Diveheller: (English): mó silêncio`

#### ২. শেষ আগত ভাষায় স্বয়ংক্রিয় উত্তর (`>>বার্তা`)
আপনার চ্যাট বার্তার শুরুতে `>>` যোগ করলে আপনার লেখাটি শেষ প্রাপ্ত সতীর্থের বার্তার ভাষায় স্বয়ংক্রিয়ভাবে অনূদিত হবে:
- চ্যাটে আপনার ইনপুট: `>>sim, está calmo demais`
- সতীর্থ দেখতে পান: `yes, it is too quiet`

#### ৩. নির্দিষ্ট / ইচ্ছামতো ভাষা নির্বাচন (`লক্ষ্য ভাষা>>বার্তা`)
ভাষার নামের পরে `>>` লিখে যেকোনো সময় নির্দিষ্ট কোনো ভাষায় আপনার বার্তাটি নির্দেশ করুন:

| চ্যাট ইনপুট কমান্ড | লক্ষ্য ভাষা | সতীর্থদের কাছে সম্প্রচারিত ফলাফলের উদাহরণ |
| :--- | :--- | :--- |
| `russian>>bom dia!` | Russian | `доброе утро!` |
| `english>>minas ao norte` | English | `mines to the north` |
| `japanese>>cuidado com os tiros!` | Japanese | `射線に注意せよ！` |
| `spanish>>preciso de munição` | Spanish | `necesito munición` |
| `german>>recuem para o ponto de extração` | German | `Rückzug zum Extraktionspunkt` |
| `french>>vamos defender aqui` | French | `défendons cette position` |

#### ৪. সাধারণ বহির্গামী বার্তা এবং স্ব-অনুবাদ দমন
`>>` ছাড়া একটি সাধারণ ইন-গেম চ্যাট বার্তা টাইপ করার সময় (যেমন `need ammo`, `vamos lá`), আপনার বার্তাটি সরাসরি স্ট্যান্ডার্ড মাল্টিপ্লেয়ার চ্যাটে চলে যায়। **"সাধারণ বহির্গামী বার্তা অনুবাদ করবেন না"** বিকল্পটি সক্ষম থাকলে (কুইক কন্ট্রোল বার এবং সেটিংস উভয়টিতেই ডিফল্টভাবে চালু), Babel আপনার নিজের বার্তা পুনরায় আপনার জন্য অনুবাদ করা রোধ করে। এটি বন্ধ (OFF) থাকলে, Babel সাধারণ স্থানীয় বার্তাগুলিকেও আগত অনুবাদ প্রক্রিয়ার মাধ্যমে পরিচালনা করবে।

#### ৫. কৌশলগত দ্রুত চ্যাট শর্টকাট
চ্যাট প্রম্পট না খুলেই মাল্টিপ্লেয়ার চ্যাটে প্রিসেট কলআউট অবিলম্বে সম্প্রচার করতে খেলার সময় যেকোনো কনফিগার করা দ্রুত চ্যাট হটকি (যেমন `NumPad 1`-`NumPad 9`) টিপুন। সমস্ত কী-প্রেস কোনো বাধা ছাড়াই গেমে চলে যায়, ফলে আপনার নিয়ন্ত্রণের স্বাভাবিক গতি বজায় থাকে।

#### ৬. কৌশলগত দ্রুত চ্যাট রেফারেন্স ওভারলে (`Numpad +`)
সমস্ত সক্রিয় দ্রুত চ্যাট প্রিসেট তালিকাভুক্ত অন-স্ক্রিন রেফারেন্স ওভারলে টগল করতে যেকোনো সময় `Numpad +` (বা **দ্রুত চ্যাট** ট্যাবে আপনার রেকর্ড করা শর্টকাট) টিপুন। ওভারলেটি স্ক্রিনের ডানদিকে উলম্বভাবে কেন্দ্রে সারিবদ্ধ হয়ে প্রদর্শিত হয়, প্রতিটি সক্রিয় প্রিসেট `[<শর্টকাট>] <বার্তা>` আকারে (বার্তা ৩০ অক্ষরে সীমাবদ্ধ) টোস্টের মতো মৃদু ভিজ্যুয়াল স্টাইলে দেখায়।
> [!NOTE]
> **ডিসপ্লে মোডের প্রয়োজনীয়তা:** গেমের উপর উইন্ডোজ ওভারলে উইন্ডো প্রদর্শিত হওয়ার জন্য ইন-গেমে ভিডিও সেটিংসে Helldivers-কে অবশ্যই **Borderless Fullscreen** (বা Windowed) মোডে চলার জন্য কনফিগার করতে হবে।

#### ৭. বিরতি, পুনরায় শুরু এবং বৈশিষ্ট্য টগল
- **গ্লোবাল বিরতি / পুনরায় শুরু (`Ctrl + F10`):** মাস্টার সুইচ যা অনুবাদ ইন্টারসেপশন এবং দ্রুত চ্যাট বার্তা সম্প্রচার উভয়কেই সুন্দরভাবে স্থগিত/পুনরায় শুরু করে।
- **শুধুমাত্র অনুবাদ টগল করুন (`Ctrl + F11`):** অন-স্ক্রিন টোস্ট বিজ্ঞপ্তি সহ শুধুমাত্র অনুবাদ বৈশিষ্ট্য চালু বা বন্ধ করে। দ্রুত চ্যাট স্বাভাবিকভাবে কাজ করতে থাকে।
- **শুধুমাত্র দ্রুত চ্যাট টগল করুন (`Ctrl + F12`):** অন-স্ক্রিন টোস্ট বিজ্ঞপ্তি সহ শুধুমাত্র দ্রুত চ্যাট বার্তা সম্প্রচার চালু বা বন্ধ করে। ইন-গেম চ্যাট অনুবাদ স্বাভাবিকভাবে কাজ করতে থাকে।
*(সমস্ত শর্টকাট **সেটিংস** এবং **দ্রুত চ্যাট** ট্যাবে ক্লিক-টু-রেকর্ড বোতাম ব্যবহার করে কাস্টমাইজ করা যায়)।*

#### ৮. রপ্তানি এবং স্থায়ী চ্যাট লগ
টাইমস্ট্যাম্প, খেলোয়াড়ের নাম, মূল বার্তা, অনুবাদ এবং লেটেন্সি সহ আপনার চ্যাট ইতিহাস একটি `.txt` নথিতে সংরক্ষণ করতে অনুবাদ ও লগ ট্যাবে যেকোনো সময় **লগ রপ্তানি করুন**-এ ক্লিক করুন। অ্যাসিঙ্ক্রোনাস ব্যাচ ডিস্ক রাইটের মাধ্যমে অ্যাপ চালুর মধ্যে চ্যাট বার্তাগুলি টেবিলে স্থায়ী থাকে (সেটিংসে স্টোরেজ সীমা ০ থেকে ১০০ MB পর্যন্ত কনফিগারযোগ্য, সাথে একটি **লগ মেমরি সাফ করুন** বোতাম রয়েছে)।

#### ৯. ইন্টারেক্টিভ বার্তা লিঙ্ক
দলের চ্যাট বার্তাগুলিতে `http://` বা `https://` URL থাকলে সেগুলি **মূল বার্তা** কলামে ক্লিকযোগ্য লিঙ্ক হিসেবে রেন্ডার হয়। ক্লিক করা হলে, আপনার ডিফল্ট ওয়েব ব্রাউজারে খোলার আগে একটি নিশ্চিতকরণ ডায়ালগ আপনাকে জিজ্ঞাসা করে যে আপনি লিঙ্কটি বিশ্বাস করেন কিনা।



## ৪. ডেভেলপমেন্ট (সোর্স থেকে বিল্ড)

### ডেভেলপার প্রয়োজনীয়তা
আপনি যদি সোর্স কোড থেকে প্রজেক্টটি কম্পাইল এবং বিল্ড করতে চান:
- **অপারেটিং সিস্টেম:** Windows 10 / 11 64-বিট (x64)।
- **.NET 10 SDK:** [.NET 10 SDK](https://dotnet.microsoft.com/download/dotnet/10.0) (`net10.0-windows`)।
- **MSYS2 MinGW64 টুলচেইন (Clang++, GCC, Make):** `mingw-w64-x86_64-clang`, `mingw-w64-x86_64-gcc` এবং `mingw-w64-x86_64-make` প্যাকেজ সহ [MSYS2](https://www.msys2.org/) - নেটিভ হুক লাইব্রেরি (`BabelHook.dll`) সংকলন এবং ইন-গেম বুটস্ট্র্যাপ স্ক্রিপ্ট (`babel_bootstrap.lua`)-কে বাইটকোডে কম্পাইল করার জন্য অফিসিয়াল LuaJIT 2.0 সাবমডিউল (`vendor/luajit`) বিল্ড করতে প্রয়োজনীয়।
- **Git:** Git for Windows (MinHook অ্যামালগামেশন এবং LuaJIT 2.0-এর জন্য রিকার্সিভ সাবমডিউল সহ)।

### স্বয়ংক্রিয় পরিবেশ সেটআপ
রিপোজিটরি রুটে `setup.bat`-এ ডাবল-ক্লিক করুন (বা PowerShell-এ `setup.ps1` চালান)। এটি স্বয়ংক্রিয়ভাবে অনুপস্থিত পূর্বশর্তগুলি যাচাই এবং ইনস্টল করে:
1. ৬৪-বিট উইন্ডোজ পরিবেশ যাচাই করে।
2. .NET 10 SDK পরীক্ষা করে (অনুপস্থিত থাকলে `winget`-এর মাধ্যমে স্বয়ংক্রিয় ইনস্টল করে)।
3. MSYS2 MinGW64 টুলচেইন (Clang++, GCC এবং Make) পরীক্ষা করে। অনুপস্থিত থাকলে, `winget`-এর মাধ্যমে MSYS2 স্বয়ংক্রিয়ভাবে ইনস্টল করে এবং `pacman`-এর মাধ্যমে প্রয়োজনীয় প্যাকেজগুলি (`mingw-w64-x86_64-clang`, `mingw-w64-x86_64-gcc` এবং `mingw-w64-x86_64-make`) ইনস্টল করে।
4. সাবমডিউল (`vendor/luajit`) থেকে LuaJIT 2.0 কম্পাইলার আরম্ভ এবং বিল্ড করে।
5. স্বয়ংক্রিয়ভাবে নিশ্চিত করে যে `C:\msys64\mingw64\bin` এবং `C:\msys64\usr\bin` PATH-এ যুক্ত হয়েছে।
6. MinHook অ্যামালগামেশন নির্ভরতা যাচাই করে এবং একটি প্রাথমিক বিল্ড স্যানিটি চেক চালায়।

### মাস্টার বিল্ড এবং রিলিজ প্যাকেজিং
পূর্ববর্তী আর্টিফ্যাক্টগুলি পরিষ্কার করতে, নেটিভ হুক DLL কম্পাইল করতে, সমস্ত ইউনিট টেস্ট চালাতে এবং রিলিজ প্যাকেজ একত্রিত করতে:
```powershell
pwsh -File build.ps1
```
আউটপুট ডিরেক্টরিটি `dist/Helldivers1Babel-vX.Y.Z/`-এ প্যাকেজ করা হবে।

### ম্যানুয়াল ধাপে ধাপে বিল্ড
```powershell
# ১. নেটিভ হুক DLL বিল্ড করুন (স্বয়ংক্রিয়ভাবে luajit দিয়ে babel_bootstrap.lua কম্পাইল করে)
pwsh -File src/Babel.Hook/build.ps1

# ২. .NET 10 সমাধান বিল্ড করুন
dotnet build Helldivers1Babel.slnx

# ৩. স্বয়ংক্রিয় টেস্ট স্যুট চালান
dotnet test
```
