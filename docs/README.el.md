## 1. Επισκόπηση & Κύρια Χαρακτηριστικά

- **Αμφίδρομη Μετάφραση Συνομιλίας σε Πραγματικό Χρόνο:**
  - **Εισερχόμενα Μηνύματα:** Εντοπίζει αυτόματα τη γλώσσα των συμπαικτών σας, μεταφράζει τα μηνύματα στη γλώσσα προορισμού που επιλέξατε (υποστηρίζει έως και 28 γλώσσες, συμπεριλαμβανομένων των Πορτογαλικών PT-BR, Αγγλικών, Ισπανικών, Ρωσικών, Κινεζικών, Ιαπωνικών, Γαλλικών, Γερμανικών κ.ά.) και τα εμφανίζει **τοπικά** στη συνομιλία του παιχνιδιού, **διατηρώντας πιστά το αρχικό όνομα παίκτη και τον χρωματικό κώδικα** (P1 Χρυσό, P2 Μπλε, P3 Μοβ, P4 Κυανό).
  - **Εξερχόμενα Μηνύματα:** Πληκτρολογήστε `[γλώσσα_προορισμού]>>μήνυμα` ή απλά `>>μήνυμα` για αυτόματη απάντηση στη γλώσσα του τελευταίου εισερχόμενου μηνύματος συμπαίκτη. Το μεταφρασμένο κείμενο μεταδίδεται μέσω RPC πολλών παικτών, ώστε οι διεθνείς συμπαίκτες να το διαβάζουν στη φυσική τους γλώσσα.
- **Μόνιμες Καταγραφές Συνομιλίας & Εξαγωγή σε Αρχείο:** Πλήρης παρακολούθηση ιστορικού συνομιλίας συνεδρίας με χρονικές σημάνσεις, ονόματα παικτών, χρώματα, εντοπισμένες γλώσσες πηγής και καθυστέρηση μετάφρασης. Οι καταγραφές παραμένουν στον πίνακα ακόμα και μετά την επανεκκίνηση της εφαρμογής μέσω ελαφρών ασύγχρονων ομαδικών εγγραφών στο δίσκο (διαμορφώσιμο), με δυνατότητα εξαγωγής σε αρχείο `.txt` με ένα κλικ.
- **Αναζητήσιμο Ιστορικό Συνομιλίας:** Πλήρως αναζητήσιμο ιστορικό συνομιλίας με φιλτράρισμα σε όλες τις στήλες.

![Το Helldivers 1 Babel σε δράση](screenshots/screenshot.png)

- **Τακτική Γρήγορη Συνομιλία (10 Προσαρμόσιμες Θέσεις):** 10 προσαρμόσιμες, προκαθορισμένες θέσεις τακτικών μηνυμάτων, καθεμία αντιστοιχισμένη σε διαμορφώσιμες από τον χρήστη συντομεύσεις πληκτρολογίου (π.χ. Numpad 0-9 ή προσαρμοσμένους συνδυασμούς), για άμεση μετάδοση τακτικών αναφορών στη συνομιλία πολλών παικτών του παιχνιδιού.
- **Μήνυμα Αυτόματου Καλωσορίσματος:** Μεταδίδει αυτόματα ένα προσαρμόσιμο μήνυμα καλωσορίσματος στη συνομιλία του παιχνιδιού όταν φιλοξενείτε ένα lobby και συνδέεται ένας νέος παίκτης.

![Γρήγορη Συνομιλία](screenshots/quick-chat.png)

- **Επικάλυψη Αναφοράς Γρήγορης Συνομιλίας στην Οθόνη:** Ενεργοποιήστε ή απενεργοποιήστε μια αιωρούμενη επικάλυψη αναφοράς (που δεν παίρνει εστίαση) στη δεξιά πλευρά της οθόνης με το `Numpad +` (ή την καταγεγραμμένη συντόμευσή σας), για να ελέγχετε γρήγορα όλες τις ενεργές τακτικές εντολές και συντομεύσεις εντός του παιχνιδιού. *(Απαιτείται η εκτέλεση του Helldivers σε λειτουργία Borderless Fullscreen ή Windowed).*

![Επικάλυψη Γρήγορης Συνομιλίας](screenshots/overlay.png)

- **Υποστήριξη Πολυγλωσσικού Περιβάλλοντος Χρήστη:** Υποστηρίζει 28 γλώσσες.
- **Αρχιτεκτονική Προσαρμογέα Παρόχων:** Κατασκευασμένο με αρθρωτή διεπαφή παρόχου τεχνητής νοημοσύνης. Συνοδεύεται από έναν βελτιστοποιημένο προσαρμογέα μηδενικής καθυστέρησης σκέψης για το **Google Gemini** (`gemini-flash-lite-latest` / `gemini-2.0-flash-lite`), με επεκτάσιμες συμβάσεις για το OpenAI, το Claude και το DeepSeek (σύντομα διαθέσιμα).
- **Ρύθμιση Τόνου Μετάφρασης:** Χαλαρός: ανεπίσημη αργκό παιχνιδιών και τακτική ορολογία gamer / Κανονικός: φυσικός τόνος συνομιλίας χωρίς αργκό gaming.
- **Καθολική Συντόμευση Παύσης / Συνέχισης:** Πατήστε `Ctrl + F10` (ή τη διαμορφωμένη συντόμευσή σας) ανά πάσα στιγμή για εναλλαγή του βοηθού μεταξύ **Ενεργό** και **Σε παύση**. Η παύση αναστέλλει καθαρά τόσο τη μετάφραση συνομιλίας όσο και τη μετάδοση μηνυμάτων Γρήγορης Συνομιλίας.
- **Εξειδικευμένες Συντομεύσεις Λειτουργιών:**
  - **Εναλλαγή Μόνο Μετάφρασης:** Πατήστε `Ctrl + F11` (ή την καταγεγραμμένη συντόμευσή σας) για άμεση παύση ή συνέχιση της μετάφρασης συνομιλίας χωρίς να επηρεάζεται η Γρήγορη Συνομιλία (με ειδοποίηση οθόνης toast).
  - **Εναλλαγή Μόνο Γρήγορης Συνομιλίας:** Πατήστε `Ctrl + F12` (ή την καταγεγραμμένη συντόμευσή σας) για άμεση παύση ή συνέχιση των μηνυμάτων Γρήγορης Συνομιλίας χωρίς να επηρεάζεται η μετάφραση (με ειδοποίηση οθόνης toast).

![Ρυθμίσεις](screenshots/settings.png)

- **Ασφαλής Αποθήκευση Διαπιστευτηρίων (DPAPI):** Ευαίσθητες προτιμήσεις, όπως τα κλειδιά API του παρόχου AI, κρυπτογραφούνται κατά την αποθήκευση χρησιμοποιώντας το Windows Data Protection API (DPAPI, εμβέλεια `CurrentUser`). Τα διαπιστευτήρια δεν αποθηκεύονται ποτέ σε απλό κείμενο σε αρχεία ρυθμίσεων και μπορούν να αποκρυπτογραφηθούν μόνο στον τοπικό σας υπολογιστή από τον λογαριασμό σας στα Windows.
- **Μηδενική Τηλεμετρία & Πλήρης Ιδιωτικότητα:** Αυτό το εργαλείο δεν συλλέγει, δεν καταγράφει και δεν στέλνει δεδομένα χρήστη ή τηλεμετρίας. Όλα τα αιτήματα μετάφρασης επικοινωνούν άμεσα και αποκλειστικά με το διαμορφωμένο τελικό σημείο του παρόχου AI χρησιμοποιώντας τα προσωπικά σας διαπιστευτήρια API.
- **100% Μη Παρεμβατικό (Μηδενική Τροποποίηση Αρχείων Παιχνιδιού):** Κανένα αρχείο ή αρχειοθήκη του παιχνιδιού δεν αποσυμπιέζεται ούτε τροποποιείται. Τα αρχεία του παιχνιδιού σας παραμένουν 100% αυθεντικά και ανέπαφα.




## 2. Εγκατάσταση & Ρύθμιση

### Απαιτήσεις Συστήματος
Εάν εκτελείτε την προ-μεταγλωττισμένη αυτόνομη έκδοση (`HD1-Babel.exe`):
- **Λειτουργικό Σύστημα:** Windows 10 / 11 64-bit (x64).
- **Περιβάλλον Εκτέλεσης:** [Microsoft .NET 10 Desktop Runtime (x64)](https://aka.ms/dotnet/10.0/windowsdesktop-runtime-win-x64.exe) (απευθείας πρόγραμμα εγκατάστασης).
- **Παιχνίδι-Στόχος:** *Helldivers* (2015) στο Steam (64-bit `helldivers.exe`).

### Απόκτηση Δωρεάν Κλειδιού AI API
- **Διαπιστευτήρια Παρόχου AI:** Κλειδί API του Google Gemini (αποκτήστε δωρεάν προσωπικό κλειδί από το [Google AI Studio](https://aistudio.google.com/) ([Δείτε αυτό το εκπαιδευτικό βίντεο](https://www.youtube.com/watch?v=YHFMrZD-_3g))).
- **Πρόσβαση στο Διαδίκτυο:** Απαιτείται για τις κλήσεις του API μετάφρασης.

### Λήψη & Εγκατάσταση (Προ-μεταγλωττισμένη Έκδοση)

**Δεν** χρειάζεται να εγκαταστήσετε εργαλεία προγραμματιστή ούτε να κάνετε μεταγλώττιση από τον πηγαίο κώδικα για να χρησιμοποιήσετε το Babel ([εκτός αν το επιθυμείτε](#4-ανάπτυξη-κατασκευή-από-τον-πηγαίο-κώδικα)):
1. Μεταβείτε στην ενότητα **[Releases](https://github.com/difinim/helldivers1-babel/releases)** στη δεξιά πλευρά της σελίδας του έργου στο GitHub.
2. Στην πιο πρόσφατη έκδοση, αναπτύξτε τη λίστα **Assets**.
3. Κάντε λήψη του αυτόνομου αρχείου διανομής: **`Helldivers1Babel-v<version>-win-x64.zip`**.
4. Εξαγάγετε το αρχείο zip οπουδήποτε στον υπολογιστή σας (π.χ. `C:\GamesTools\Helldivers1Babel`).
5. Ανοίξτε τον φάκελο και εκτελέστε το **`HD1-Babel.exe`**.

> [!NOTE]
> **Προαπαιτούμενο:** Οι τελικοί χρήστες χρειάζονται μόνο το δωρεάν [Microsoft .NET 10 Desktop Runtime (x64)](https://dotnet.microsoft.com/download/dotnet/10.0). Δεν απαιτείται μεταγλωττιστής C++, SDK ή εργαλειοθήκη ανάπτυξης για την εκτέλεση της έκδοσης.

> [!NOTE]
> **Προσοχή**: Επειδή το InjectorService.cs χρησιμοποιεί τυπικά API έγχυσης διεργασιών των Windows (`VirtualAllocEx` + `WriteProcessMemory` + `CreateRemoteThread`), το Windows Defender ή προγράμματα προστασίας από ιούς τρίτων _**ενδέχεται**_ να ενεργοποιήσουν ευρετικό εντοπισμό (heuristic detection, π.χ. Generic HackTool). Αυτή είναι φυσιολογική συμπεριφορά για εργαλεία εισαγωγής mods σε παιχνίδια και μπορείτε με ασφάλεια να το προσθέσετε στη λίστα εξαιρέσεων (allowlist).



## 3. Οδηγός Χρήσης

### Ξεκινώντας
1. Εκκινήστε το **Helldivers 1 Babel** (`HD1-Babel.exe`).
2. Κατά την πρώτη εκκίνηση, ανοίξτε την καρτέλα **Ρυθμίσεις**:
   - Εισαγάγετε το **Κλειδί API Google Gemini** (αποθηκεύεται με ασφάλεια μέσω κρυπτογράφησης Windows DPAPI).
   - Επιλέξτε τη γλώσσα προορισμού σας (π.χ. `Ελληνικά` ή `Portuguese (PT-BR)`).
   - Κάντε κλικ στο **Δοκιμή Σύνδεσης API** για να επιβεβαιώσετε το κλειδί και την καθυστέρηση.
   - Προσαρμόστε τη συντόμευση **Παύσης / Συνέχισης** αν το επιθυμείτε (προεπιλογή: `Ctrl + F10`).
3. Διαμορφώστε τα τακτικά σας μηνύματα στην καρτέλα **Γρήγορη Συνομιλία** (π.χ. αντιστοιχίστε τα πλήκτρα Numpad 0-9 στα επιθυμητά μηνύματα).
4. Εκκινήστε το **Helldivers** στο Steam. Το Babel εντοπίζει αυτόματα το `helldivers.exe`.

### Επικοινωνία Εντός Παιχνιδιού & Περιπτώσεις Χρήσης

#### 1. Αυτόματη Εισερχόμενη Μετάφραση
Τα εισερχόμενα μηνύματα από συμπαίκτες εντοπίζονται και μεταφράζονται άμεσα στη γλώσσα προορισμού σας, και εμφανίζονται στη συνομιλία του παιχνιδιού με το αρχικό όνομα και χρώμα του παίκτη:
- Συμπαίκτης (Αγγλικά): `so quiet`
- Συνομιλία Παιχνιδιού: `Diveheller: (Αγγλικά): τόση ησυχία`

#### 2. Αυτόματη Απάντηση στην Τελευταία Εισερχόμενη Γλώσσα (`>>μήνυμα`)
Προσθέτοντας το πρόθεμα `>>` στο μήνυμά σας, μεταφράζετε αυτόματα το κείμενό σας στη γλώσσα του τελευταίου εισερχόμενου μηνύματος συμπαίκτη:
- Η καταχώρισή σας στη συνομιλία: `>>ναι, επικρατεί υπερβολική ησυχία`
- Τι βλέπει ο συμπαίκτης: `yes, it is too quiet`

#### 3. Ρητή / Προαιρετική Επιλογή Γλώσσας (`γλώσσα προορισμού>>μήνυμα`)
Κατευθύνετε το μήνυμά σας σε μια συγκεκριμένη γλώσσα ανά πάσα στιγμή, βάζοντας ως πρόθεμα το όνομα της γλώσσας ακολουθούμενο από `>>`:

| Εντολή Εισαγωγής Συνομιλίας | Γλώσσα Προορισμού | Παράδειγμα Αποτελέσματος που Μεταδίδεται |
| :--- | :--- | :--- |
| `russian>>καλημέρα!` | Ρωσικά | `доброе утро!` |
| `english>>νάρκες στα βόρεια` | Αγγλικά | `mines to the north` |
| `japanese>>προσοχή στα πυρά!` | Ιαπωνικά | `射線に注意せよ！` |
| `spanish>>χρειάζομαι πυρομαχικά` | Ισπανικά | `necesito munición` |
| `german>>υποχωρήστε στο σημείο εξόρυξης` | Γερμανικά | `Rückzug zum Extraktionspunkt` |
| `french>>ας υπερασπιστούμε αυτό το σημείο` | Γαλλικά | `défendons cette position` |

#### 4. Τυπικά Εξερχόμενα Μηνύματα & Αποτροπή Αυτομετάφρασης
Όταν πληκτρολογείτε ένα τυπικό μήνυμα συνομιλίας χωρίς `>>` (π.χ. `need ammo`, `πάμε`), το μήνυμά σας μεταδίδεται απευθείας μέσω της αρχικής συνομιλίας πολλών παικτών. Με ενεργοποιημένη την επιλογή **"Να μην μεταφράζονται τα τυπικά εξερχόμενα μηνύματα"** (ενεργή από προεπιλογή τόσο στη γραμμή γρήγορου ελέγχου όσο και στις Ρυθμίσεις), το Babel αποτρέπει τη μετάφραση του δικού σας μηνύματος πίσω σε εσάς. Εάν απενεργοποιηθεί, το Babel θα επεξεργάζεται και τα τυπικά τοπικά μηνύματα μέσω της ροής εισερχόμενης μετάφρασης.

#### 5. Συντομεύσεις Τακτικής Γρήγορης Συνομιλίας
Πατήστε οποιοδήποτε ρυθμισμένο πλήκτρο συντόμευσης γρήγορης συνομιλίας (π.χ. `NumPad 1`-`NumPad 9`) καθώς παίζετε για να μεταδώσετε άμεσα προκαθορισμένες αναφορές στη συνομιλία πολλών παικτών, χωρίς να χρειάζεται να ανοίξετε το πεδίο συνομιλίας. Όλα τα πατήματα πλήκτρων περνούν απρόσκοπτα στο παιχνίδι, διασφαλίζοντας ότι ο έλεγχος παραμένει άμεσος.

#### 6. Επικάλυψη Αναφοράς Γρήγορης Συνομιλίας (`Numpad +`)
Πατήστε `Numpad +` (ή την καταγεγραμμένη συντόμευση που διαμορφώσατε στην καρτέλα **Γρήγορη Συνομιλία**) ανά πάσα στιγμή για να εμφανίσετε μια επικάλυψη αναφοράς στην οθόνη που παραθέτει όλες τις ενεργές προεπιλογές Γρήγορης Συνομιλίας. Η επικάλυψη εμφανίζεται στη δεξιά πλευρά και στο κέντρο καθ' ύψος της οθόνης, δείχνοντας κάθε ενεργή προεπιλογή στη μορφή `[<συντόμευση>] <μήνυμα>` (με τα μηνύματα να περικόπτονται στους 30 χαρακτήρες) χρησιμοποιώντας το ίδιο διακριτικό στυλ με τις ειδοποιήσεις.
> [!NOTE]
> **Απαίτηση Λειτουργίας Οθόνης:** Το Helldivers πρέπει να έχει ρυθμιστεί σε λειτουργία **Borderless Fullscreen** (ή Windowed) στις ρυθμίσεις βίντεο εντός του παιχνιδιού, ώστε τα παράθυρα επικάλυψης των Windows να μπορούν να εμφανίζονται πάνω από το παιχνίδι.

#### 7. Παύση, Συνέχιση & Διακόπτες Λειτουργιών
- **Καθολική Παύση / Συνέχιση (`Ctrl + F10`):** Κύριος διακόπτης που αναστέλλει/συνεχίζει ομαλά τόσο την υποκλοπή μετάφρασης όσο και τη μετάδοση μηνυμάτων Γρήγορης Συνομιλίας.
- **Εναλλαγή Μόνο Μετάφρασης (`Ctrl + F11`):** Ενεργοποιεί ή απενεργοποιεί μόνο τη δυνατότητα μετάφρασης με ειδοποίηση οθόνης toast. Η Γρήγορη Συνομιλία συνεχίζει να λειτουργεί κανονικά.
- **Εναλλαγή Μόνο Γρήγορης Συνομιλίας (`Ctrl + F12`):** Ενεργοποιεί ή απενεργοποιεί μόνο τη μετάδοση μηνυμάτων Γρήγορης Συνομιλίας με ειδοποίηση οθόνης toast. Η μετάφραση συνομιλίας του παιχνιδιού συνεχίζει να λειτουργεί κανονικά.
*(Όλες οι συντομεύσεις μπορούν να προσαρμοστούν στις καρτέλες **Ρυθμίσεις** και **Γρήγορη Συνομιλία** χρησιμοποιώντας τα κουμπιά καταγραφής συντομεύσεων).*

#### 8. Εξαγωγή & Μόνιμες Καταγραφές Συνομιλίας
Κάντε κλικ στην επιλογή **Εξαγωγή Καταγραφών** στην καρτέλα Μετάφραση & Καταγραφές ανά πάσα στιγμή για να επιλέξετε μια τοποθεσία και να εξάγετε το ιστορικό συνομιλίας σας (με χρονικές σημάνσεις, ονόματα παικτών, αρχικά μηνύματα, μεταφράσεις και καθυστερήσεις) σε ένα έγγραφο `.txt`. Τα μηνύματα συνομιλίας διατηρούνται αυτόματα στον πίνακα μεταξύ των εκκινήσεων της εφαρμογής μέσω ασύγχρονων ομαδικών εγγραφών στο δίσκο (το όριο αποθήκευσης διαμορφώνεται από 0 έως 100 MB στις Ρυθμίσεις, με κουμπί **Εκκαθάριση μνήμης καταγραφών**).

#### 9. Διαδραστικοί Σύνδεσμοι Μηνυμάτων
Μηνύματα συνομιλίας ομάδας που περιέχουν συνδέσμους `http://` ή `https://` εμφανίζονται ως σύνδεσμοι με δυνατότητα κλικ στη στήλη **Αρχικό Μήνυμα**. Όταν κάνετε κλικ, εμφανίζεται ένα παράθυρο επιβεβαίωσης που σας ζητά να επαληθεύσετε εάν εμπιστεύεστε τον σύνδεσμο πριν τον ανοίξετε στο προεπιλεγμένο πρόγραμμα περιήγησης ιστού.



## 4. Ανάπτυξη (Κατασκευή από τον Πηγαίο Κώδικα)

### Απαιτήσεις Προγραμματιστή
Εάν μεταγλωττίζετε και κατασκευάζετε το έργο από τον πηγαίο κώδικα:
- **Λειτουργικό Σύστημα:** Windows 10 / 11 64-bit (x64).
- **.NET 10 SDK:** [.NET 10 SDK](https://dotnet.microsoft.com/download/dotnet/10.0) (`net10.0-windows`).
- **Εργαλειοθήκη MSYS2 MinGW64 (Clang++, GCC, Make):** [MSYS2](https://www.msys2.org/) με τα πακέτα `mingw-w64-x86_64-clang`, `mingw-w64-x86_64-gcc` και `mingw-w64-x86_64-make` - απαιτείται για τη μεταγλώττιση της εγγενούς βιβλιοθήκης hook (`BabelHook.dll`) και την κατασκευή της επίσημης υπομονάδας LuaJIT 2.0 (`vendor/luajit`) για τη μεταγλώττιση του σεναρίου εκκίνησης εντός του παιχνιδιού (`babel_bootstrap.lua`) σε bytecode.
- **Git:** Git for Windows (με αναδρομικές υπομονάδες για το MinHook και το LuaJIT 2.0).


### Αυτοματοποιημένη Ρύθμιση Περιβάλλοντος
Κάντε διπλό κλικ στο `setup.bat` (ή εκτελέστε το `setup.ps1` στο PowerShell) στον ριζικό κατάλογο του αποθετηρίου. Επαληθεύει και εγκαθιστά αυτόματα τα προαπαιτούμενα που λείπουν:
1. Επαληθεύει περιβάλλον Windows 64-bit.
2. Ελέγχει για το .NET 10 SDK (αυτόματη εγκατάσταση μέσω `winget` εάν λείπει).
3. Ελέγχει για την εργαλειοθήκη MSYS2 MinGW64 (Clang++, GCC και Make). Εάν λείπει, εγκαθιστά αυτόματα το MSYS2 μέσω `winget` και εγκαθιστά τα απαιτούμενα πακέτα (`mingw-w64-x86_64-clang`, `mingw-w64-x86_64-gcc` και `mingw-w64-x86_64-make`) μέσω `pacman`.
4. Αρχικοποιεί και κατασκευάζει τον μεταγλωττιστή LuaJIT 2.0 από την υπομονάδα (`vendor/luajit`).
5. Διασφαλίζει αυτόματα ότι τα `C:\msys64\mingw64\bin` και `C:\msys64\usr\bin` προστίθενται στη μεταβλητή περιβάλλοντος PATH.
6. Επαληθεύει τις εξαρτήσεις MinHook και εκτελεί έναν αρχικό έλεγχο ορθότητας κατασκευής.

### Κύρια Μεταγλώττιση & Πακετάρισμα Έκδοσης
Για να καθαρίσετε προηγούμενα παραγόμενα αρχεία, να μεταγλωττίσετε το εγγενές hook DLL, να εκτελέσετε όλες τις δοκιμές μονάδας και να συναρμολογήσετε το πακέτο έκδοσης:
```powershell
pwsh -File build.ps1
```
Ο κατάλογος εξόδου θα συσκευαστεί στο `dist/Helldivers1Babel-vX.Y.Z/`.

### Χειροκίνητη Μεταγλώττιση Βήμα προς Βήμα
```powershell
# 1. Κατασκευάστε το εγγενές hook DLL (μεταγλωττίζει αυτόματα το babel_bootstrap.lua με το luajit)
pwsh -File src/Babel.Hook/build.ps1

# 2. Κατασκευάστε τη λύση .NET 10
dotnet build Helldivers1Babel.slnx

# 3. Εκτελέστε τις αυτοματοποιημένες σουίτες δοκιμών
dotnet test
```
