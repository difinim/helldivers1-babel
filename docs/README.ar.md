## 1. نظرة عامة والميزات الرئيسية

- **ترجمة فورية ثنائية الاتجاه للمحادثة:**
  - **الرسائل الواردة:** يكتشف لغة أعضاء الفريق تلقائياً، ويترجم الرسائل إلى لغتك المستهدفة المختارة (يدعم ما يصل إلى 28 لغة مستهدفة، بما في ذلك البرتغالية البرازيلية PT-BR، والإنجليزية، والإسبانية، والروسية، والصينية، واليابانية، والفرنسية، والألمانية، وغيرها)، ويعرضها **محلياً** داخل محادثة اللعبة مع **الحفاظ بدقة على اسم اللاعب الأصلي ولونه التكتيكي** (P1 ذهبي، P2 أزرق، P3 بنفسجي، P4 سماوي).
  - **الرسائل الصادرة:** اكتب `[target_language]>>رسالتك` أو ببساطة `>>رسالتك` للرد التلقائي بنفس لغة آخر رسالة واردة من أحد الزملاء. يتم بث النص المترجم عبر استدعاء الإجراء البعيد (RPC) للعب الجماعي ليقرأه زملاؤك بلغتهم الأم.
- **سجلات محادثة دائمة وتصدير إلى ملفات:** تتبع كامل لتاريخ محادثات الجلسة مع الطوابع الزمنية، وأسماء اللاعبين، وألوانهم، ولغات المصدر المكتشفة، وزمن استجابة الترجمة. تظل السجلات محفوظة في الجدول عبر عمليات إعادة تشغيل التطبيق بفضل عمليات الكتابة غير المتزامنة على القرص (قابلة للتكوين)، مع ميزة التصدير بنقرة واحدة إلى ملف `.txt`.
- **سجلات محادثة قابلة للبحث:** تاريخ محادثة قابل للبحث بالكامل مع تصفية أي من الأعمدة.

![Helldivers 1 Babel أثناء العمل](screenshots/screenshot.png)

- **محادثة تكتيكية سريعة (10 خانات مخصصة):** 10 خانات لرسائل تكتيكية محددة مسبقاً وقابلة للتخصيص، كل منها مربوط بمفاتيح اختصار قابلة للتعديل (مثل Numpad 0-9 أو اختصارات مخصصة) لبث النداءات التكتيكية فوراً في محادثة اللعب الجماعي.
- **رسالة ترحيب تلقائية للمحادثة السريعة:** بث رسالة ترحيب مخصصة تلقائياً في محادثة اللعبة عند استضافة غرفة وانضمام لاعب جديد.

![المحادثة السريعة](screenshots/quick-chat.png)

- **شاشة عرض تكتيكية منبثقة للمحادثة السريعة:** قم بتبديل نافذة مرجعية عائمة غير مفعلة على الجانب الأيمن من الشاشة بالضغط على `Numpad +` (أو اختصارك المسجل) لمعاينة جميع النداءات والاختصارات التكتيكية النشطة أثناء اللعب. *(يتطلب تشغيل Helldivers في وضع ملء الشاشة بدون حواف Borderless Fullscreen أو وضع النافذة Windowed)*.

![شاشة المحادثة السريعة المنبثقة](screenshots/overlay.png)

- **واجهة مستخدم متعددة اللغات:** تدعم 28 لغة.
- **بنية محول المزودين:** مصمم بواجهة برمجية معيارية لمزودي الذكاء الاصطناعي. يأتي مزوداً بمحول محسّن وخالٍ من التفكير لـ **Google Gemini** (`gemini-flash-lite-latest` / `gemini-2.0-flash-lite`)، مع عقود مزودين قابلة للتوسيع لدعم OpenAI و Claude و DeepSeek (قيد التطوير).
- **إعداد نبرة الترجمة:** غير رسمي: مصطلحات الألعاب العامية ولغة اللاعبين التكتيكية / عادي: أسلوب محادثة طبيعي دون مصطلحات عامية.
- **اختصار عام للإيقاف المؤقت / الاستئناف:** اضغط على `Ctrl + F10` (أو اختصارك المخصص) في أي وقت للتبديل بين وضعي **نشط** و**موقوف مؤقتاً**. يؤدي الإيقاف المؤقت إلى تعليق كل من ترجمة محادثة اللعبة وبث رسائل المحادثة السريعة بسلاسة.
- **اختصارات مخصصة لكل ميزة:**
  - **تبديل الترجمة فقط:** اضغط على `Ctrl + F11` (أو اختصارك المسجل) لإيقاف أو استئناف ترجمة المحادثة فوراً دون التأثير على المحادثة السريعة (مع إشعار منبثق على الشاشة).
  - **تبديل المحادثة السريعة فقط:** اضغط على `Ctrl + F12` (أو اختصارك المسجل) لإيقاف أو استئناف نداءات المحادثة السريعة فوراً دون التأثير على الترجمة (مع إشعار منبثق على الشاشة).

![الإعدادات](screenshots/settings.png)

- **تخزين آمن لبيانات الاعتماد (DPAPI):** يتم تشفير التفضيلات الحساسة مثل رموز API لمزودي الذكاء الاصطناعي باستخدام واجهة حماية بيانات ويندوز (Windows DPAPI، نطاق `CurrentUser`). لا يتم تخزين بيانات الاعتماد كنص صريح في ملفات التكوين نهائياً، ولا يمكن فك تشفيرها إلا على جهازك المحلي بواسطة حساب ويندوز الخاص بك.
- **انعدام تام للقياس عن بُعد والخصوصية الكاملة:** لا يقوم هذا البرنامج بجمع أو تسجيل أو إرسال أي بيانات مستخدم أو بيانات قياس عن بُعد. تتصل جميع طلبات الترجمة مباشرة وحصرياً بنقطة نهاية مزود الذكاء الاصطناعي المحددة باستخدام بيانات API الشخصية الخاصة بك.
- **غير تداخلي بنسبة 100% (دون أي تعديل على ملفات اللعبة):** لا يتم تفكيك أو تعديل أي من أرشيفات اللعبة. تظل ملفات اللعبة أصلية وغير ملموسة تماماً.




## 2. الإعداد والتثبيت

### المتطلبات
إذا كنت تشغل الإصدار المستقل المبني مسبقاً (`HD1-Babel.exe`):
- **نظام التشغيل:** Windows 10 / 11 بمعمارية 64 بت (x64).
- **بيئة تشغيل سطح المكتب:** [Microsoft .NET 10 Desktop Runtime (x64)](https://aka.ms/dotnet/10.0/windowsdesktop-runtime-win-x64.exe) (مثبت مباشر).
- **اللعبة المستهدفة:** *Helldivers* (2015) على Steam (ملف `helldivers.exe` بمعمارية 64 بت).

### إعداد مفتاح AI API مجاني
- **بيانات اعتماد مزود الذكاء الاصطناعي:** مفتاح API لـ Google Gemini (احصل على مفتاح شخصي مجاني من [Google AI Studio](https://aistudio.google.com/) ([شاهد هذا الفيديو التعليمي](https://www.youtube.com/watch?v=YHFMrZD-_3g))).
- **الاتصال بالإنترنت:** مطلوب لإجراء مكالمات API الخاصة بالترجمة.

### التنزيل والتثبيت (إصدار جاهز للتشغيل)

**لا تحتاج** إلى تثبيت أدوات المطورين أو البناء من المصدر لاستخدام Babel ([ولكن إذا كنت ترغب في ذلك](#4-التطوير-البناء-من-المصدر)):
1. انتقل إلى قسم **[Releases](https://github.com/difinim/helldivers1-babel/releases)** في الجانب الأيمن من صفحة المشروع على GitHub.
2. أسفل أحدث إصدار، قم بتوسيع قائمة **Assets**.
3. قم بتنزيل أرشيف التوزيع المستقل: **`Helldivers1Babel-v<version>-win-x64.zip`**.
4. استخرج ملف zip في أي مكان على جهاز الكمبيوتر الخاص بك (مثل `C:\GamesTools\Helldivers1Babel`).
5. افتح المجلد وشغّل **`HD1-Babel.exe`**.

> [!NOTE]
> **المتطلبات المسبقة:** يحتاج المستخدمون النهائيون فقط إلى بيئة التشغيل المجانية [Microsoft .NET 10 Desktop Runtime (x64)](https://dotnet.microsoft.com/download/dotnet/10.0). لا يلزم وجود مترجم C++ أو SDK أو حزمة تطوير لتشغيل الإصدار.

> [!NOTE]
> **تنبيه**: نظراً لأن ملف InjectorService.cs يستخدم واجهات برمجة تطبيقات ويندوز القياسية لحقن العمليات (`VirtualAllocEx` + `WriteProcessMemory` + `CreateRemoteThread`)، فقد يُطلق Windows Defender أو برامج مكافحة الفيروسات تنبيهاً استكشافياً (مثل Generic HackTool). هذا سلوك طبيعي لأدوات حقن التعديلات في الألعاب ويمكن إضافته بأمان إلى قائمة الاستثناءات (allowlist).



## 3. دليل الاستخدام

### البدء
1. شغّل **Helldivers 1 Babel** (`HD1-Babel.exe`).
2. عند التشغيل الأول، افتح تبويب **الإعدادات**:
   - أدخل **مفتاح Google Gemini API** الخاص بك (يتم حفظه مشفراً بأمان عبر Windows DPAPI).
   - اختر لغتك المستهدفة (مثل `Portuguese (PT-BR)`).
   - انقر فوق **اختبار اتصال API** للتحقق من صلاحية مفتاحك وزمن الاستجابة.
   - قم بتخصيص اختصار **الإيقاف المؤقت/الاستئناف** إذا رغبت في ذلك (الافتراضي هو `Ctrl + F10`).
3. قم بتهيئة ندائك التكتيكية في تبويب **المحادثة السريعة** (مثل ربط Numpad 0-9 برسائلك المفضلة).
4. شغّل **Helldivers** على Steam. سيتعرف Babel تلقائياً على `helldivers.exe`، ويحقن `BabelHook.dll`، وينشئ اتصال IPC فائق السرعة عبر القنوات المسماة.

### التواصل أثناء اللعب وحالات الاستخدام

#### 1. الترجمة التلقائية للرسائل الواردة
يتم اكتشاف الرسائل الواردة من أعضاء الفريق وترجمتها إلى لغتك المستهدفة فوراً، وعرضها في محادثة اللعبة مع اسم اللاعب ولونه الأصليين:
- الزميل (English): `so quiet`
- محادثة اللعبة: `Diveheller: (English): mó silêncio`

#### 2. الرد التلقائي بلغة آخر رسالة واردة (`>>رسالتك`)
إضافة `>>` في بداية رسالتك يؤدي تلقائياً إلى ترجمة النص إلى لغة آخر رسالة واردة من زميلك:
- إدخالك في المحادثة: `>>sim, está calmo demais`
- ما يراه الزميل: `yes, it is too quiet`

#### 3. تحديد لغة معينة حسب الرغبة (`اللغة المستهدفة>>رسالتك`)
وجّه رسالتك إلى لغة محددة في أي وقت عبر كتابة اسم اللغة متبوعاً بـ `>>`:

| أمر إدخال المحادثة | اللغة المستهدفة | مثال للنتيجة المبثوثة للزملاء |
| :--- | :--- | :--- |
| `russian>>bom dia!` | Russian | `доброе утро!` |
| `english>>minas ao norte` | English | `mines to the north` |
| `japanese>>cuidado com os tiros!` | Japanese | `射線に注意せよ！` |
| `spanish>>preciso de munição` | Spanish | `necesito munición` |
| `german>>recuem para o ponto de extração` | German | `Rückzug zum Extraktionspunkt` |
| `french>>vamos defender aqui` | French | `défendons cette position` |

#### 4. الرسائل الصادرة العادية وتجاوز الترجمة الذاتية
عند كتابة رسالة محادثة عادية داخل اللعبة دون بادئة `>>` (مثل `need ammo` أو `vamos lá`)، يتم إرسال رسالتك مباشرة عبر محادثة اللعب الجماعي القياسية. عند تفعيل خيار **"عدم ترجمة الرسائل الصادرة العادية"** (مفعل افتراضياً في شريط التحكم السريع وفي الإعدادات)، يمنع Babel إعادة ترجمة رسالتك الخاصة إليك. وفي حال تعطيله، سيعالج Babel الرسائل المحلية العادية عبر مسار الترجمة الواردة أيضاً.

#### 5. اختصارات المحادثة التكتيكية السريعة
اضغط على أي مفتاح اختصار تم ضبطه للمحادثة السريعة (مثل `NumPad 1` إلى `NumPad 9`) أثناء اللعب لبث نداءات مسبقة فوراً دون الحاجة لفتح شريط كتابة المحادثة. تمر جميع ضغطات المفاتيح بسلاسة إلى اللعبة لضمان بقاء التحكم مستجيباً بالكامل.

#### 6. شاشة العرض التكتيكية المنبثقة للمحادثة السريعة (`Numpad +`)
اضغط على `Numpad +` (أو اختصارك المسجل في تبويب **المحادثة السريعة**) في أي وقت لتبديل شاشة عرض مرجعية تسرد جميع النداءات النشطة. تظهر الشاشة بمحاذاة اليمين وتتوسط عمودياً، وتعرض كل نداء نشط وفق النمط `[<الاختصار>] <الرسالة>` (مع تقصير الرسائل لأول 30 حرفاً) وبنفس النمط البصري الهادئ للإشعارات المنبثقة.
> [!NOTE]
> **متطلبات وضع العرض:** يجب ضبط Helldivers لتعمل في وضع **ملء الشاشة بدون حواف (Borderless Fullscreen)** أو وضع النافذة في إعدادات الفيديو داخل اللعبة لتتمكن نوافذ ويندوز المنبثقة من الظهور فوق اللعبة.

#### 7. الإيقاف المؤقت والاستئناف وتبديل الميزات
- **الإيقاف المؤقت / الاستئناف العام (`Ctrl + F10`):** المفتاح الرئيسي الذي يوقف أو يستأنف اعتراض الترجمة وبث رسائل المحادثة السريعة معاً بنظافة.
- **تبديل الترجمة فقط (`Ctrl + F11`):** يقوم بتشغيل أو إيقاف ميزة الترجمة فقط مع إشعار منبثق على الشاشة. وتستمر المحادثة السريعة في العمل بشكل طبيعي.
- **تبديل المحادثة السريعة فقط (`Ctrl + F12`):** يقوم بتشغيل أو إيقاف بث رسائل المحادثة السريعة فقط مع إشعار منبثق على الشاشة. وتستمر ترجمة المحادثة في العمل بشكل طبيعي.
*(يمكن تخصيص كافة الاختصارات في تبويبي **الإعدادات** و**المحادثة السريعة** باستخدام أزرار التسجيل بالنقر).*

#### 8. التصدير وسجلات المحادثة الدائمة
انقر فوق **تصدير السجلات** في تبويب الترجمة والسجلات في أي وقت لاختيار موقع وتصدير تاريخ محادثاتك (مع الطوابع الزمنية، وأسماء اللاعبين، والرسائل الأصلية، والترجمات، وأزمنة الاستجابة) إلى مستند `.txt`. تظل رسائل المحادثة محفوظة في الجدول تلقائياً عبر جلسات تشغيل البرنامج من خلال الكتابة غير المتزامنة على القرص (الحد الأقصى للتخزين قابل للتعديل من 0 إلى 100 ميجابايت في الإعدادات، مع زر **مسح ذاكرة السجلات**).

#### 9. روابط الرسائل التفاعلية
يتم عرض رسائل محادثة الفريق التي تحتوي على روابط `http://` أو `https://` كروابط قابلة للنقر في عمود **الرسالة الأصلية**. عند النقر، يظهر مربع حوار تأكيد يسألك عما إذا كنت تثق في الرابط قبل فتحه في متصفح الويب الافتراضي الخاص بك.



## 4. التطوير (البناء من المصدر)

### متطلبات المطورين
إذا كنت تقوم بترجمة المشروع وبنائه من الكود المصدري:
- **نظام التشغيل:** Windows 10 / 11 بمعمارية 64 بت (x64).
- **حزمة تطوير .NET 10:** [.NET 10 SDK](https://dotnet.microsoft.com/download/dotnet/10.0) (`net10.0-windows`).
- **حزمة أدوات MSYS2 MinGW64 (Clang++ و GCC و Make):** [MSYS2](https://www.msys2.org/) مع الحزم `mingw-w64-x86_64-clang` و `mingw-w64-x86_64-gcc` و `mingw-w64-x86_64-make` - مطلوبة لترجمة مكتبة الخطاف الأصلية (`BabelHook.dll`) وبناء الوحدة الفرعية الرسمية لـ LuaJIT 2.0 (`vendor/luajit`) لترجمة برنامج التمهيد داخل اللعبة (`babel_bootstrap.lua`) إلى كود بايت.
- **Git:** Git لنظام Windows (مع الوحدات الفرعية التكرارية لـ MinHook و LuaJIT 2.0).

### إعداد البيئة تلقائياً
انقر نقراً مزدوجاً على `setup.bat` (أو شغّل `setup.ps1` في PowerShell) في المجلد الرئيسي للمستودع. يتحقق البرنامج تلقائياً من المتطلبات الأساسية المفقودة ويثبتها:
1. التحقق من بيئة ويندوز 64 بت.
2. التحقق من وجود .NET 10 SDK (تثبيت تلقائي عبر `winget` إذا كان مفقوداً).
3. التحقق من حزمة أدوات MSYS2 MinGW64 (Clang++ و GCC و Make). إذا كانت مفقودة، يتم تثبيت MSYS2 تلقائياً عبر `winget` وتثبيت الحزم المطلوبة (`mingw-w64-x86_64-clang` و `mingw-w64-x86_64-gcc` و `mingw-w64-x86_64-make`) عبر `pacman`.
4. تهيئة وبناء مترجم LuaJIT 2.0 من الوحدة الفرعية (`vendor/luajit`).
5. التأكد تلقائياً من إضافة المسارات `C:\msys64\mingw64\bin` و `C:\msys64\usr\bin` إلى متغير البيئة PATH.
6. التحقق من تبعيات MinHook وإجراء فحص سلامة أولي لعملية البناء.

### البناء الرئيسي وحزم الإصدار
لتنظيف المخرجات السابقة، وترجمة مكتبة الخطاف الأصلية، وتشغيل جميع اختبارات الوحدات، وتجميع حزمة الإصدار:
```powershell
pwsh -File build.ps1
```
سيتم حزم دليل المخرجات داخل `dist/Helldivers1Babel-vX.Y.Z/`.

### البناء اليدوي خطوة بخطوة
```powershell
# 1. بناء مكتبة الخطاف الأصلية DLL (يترجم babel_bootstrap.lua تلقائياً باستخدام luajit)
pwsh -File src/Babel.Hook/build.ps1

# 2. بناء حل .NET 10
dotnet build Helldivers1Babel.slnx

# 3. تشغيل حزم الاختبارات التلقائية
dotnet test
```
