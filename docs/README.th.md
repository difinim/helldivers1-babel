## 1. ภาพรวมและฟีเจอร์หลัก

- **การแปลแชทสองทิศทางแบบเรียลไทม์:**
  - **การแปลขาเข้า:** ตรวจจับภาษาของเพื่อนร่วมทีมโดยอัตโนมัติ แปลข้อความเป็นภาษาเป้าหมายที่คุณเลือก (รองรับภาษาเป้าหมายสูงสุด 28 ภาษา รวมถึง โปรตุเกส PT-BR, อังกฤษ, สเปน, รัสเซีย, จีน, ญี่ปุ่น, ฝรั่งเศส, เยอรมัน และอื่นๆ) และแสดงผล**เฉพาะในเครื่องของคุณ (locally)** ลงในแชทของเกมโดยตรง โดย**คงชื่อผู้เล่นและรหัสสีดั้งเดิมของเพื่อนร่วมทีมไว้อย่างถูกต้องสมบูรณ์** (P1 สีทอง, P2 สีน้ำเงิน, P3 สีม่วง, P4 สีฟ้าไซแอน)
  - **การแปลขาออก:** พิมพ์ `[ภาษาเป้าหมาย]>>ข้อความ` หรือพิมพ์เพียง `>>ข้อความ` เพื่อตอบกลับอัตโนมัติในภาษาของข้อความล่าสุดที่ได้รับจากเพื่อนร่วมทีม ข้อความที่แปลแล้วจะถูกถ่ายทอดผ่าน RPC ของระบบผู้เล่นหลายคนเพื่อให้เพื่อนร่วมทีมจากต่างชาติอ่านได้ในภาษาท้องถิ่นของพวกเขา
- **การเก็บบันทึกแชทถาวรและการส่งออกไฟล์:** ติดตามประวัติการแชทตลอดเซสชันพร้อมการประทับเวลา, ชื่อผู้เล่น, สี, ภาษาต้นฉบับที่ตรวจพบ และความหน่วงในการแปล บันทึกจะยังคงอยู่ในตารางแม้จะปิดเปิดแอปใหม่ผ่านการเขียนไฟล์ลงดิสก์แบบอะซิงโครนัสเป็นชุดที่มีน้ำหนักเบา (ปรับแต่งได้) พร้อมส่งออกเป็นไฟล์ `.txt` ได้ด้วยคลิกเดียว
- **บันทึกแชทที่ค้นหาได้:** ค้นหาประวัติการแชทได้อย่างครอบคลุม กรองข้อมูลได้จากทุกคอลัมน์

![Helldivers 1 Babel ขณะทำงาน](screenshots/screenshot.png)

- **แชทด่วนเชิงยุทธวิธี (10 ช่องปรับแต่งได้):** ช่องข้อความเชิงยุทธวิธีที่กำหนดไว้ล่วงหน้า 10 ช่อง แต่ละช่องผูกเข้ากับปุ่มลัดที่ผู้ใช้ปรับแต่งได้ (เช่น Numpad 0-9 หรือการกดปุ่มผสม) เพื่อส่งคำสั่งยุทธวิธีลงในแชทผู้เล่นหลายคนในเกมได้ทันที
- **ข้อความต้อนรับอัตโนมัติของแชทด่วน:** ถ่ายทอดข้อความต้อนรับที่ปรับแต่งได้ลงในแชทของเกมโดยอัตโนมัติเมื่อเป็นโฮสต์ห้องและมีผู้เล่นอื่นเข้าร่วม

![แชทด่วน](screenshots/quick-chat.png)

- **หน้าต่างซ้อนทับอ้างอิงแชทด่วนบนหน้าจอ:** สลับเปิด/ปิดหน้าต่างซ้อนทับลอยตัวอ้างอิงคำสั่งที่ไม่รบกวนหน้าต่างเกมทางด้านขวาของหน้าจอด้วยปุ่ม `Numpad +` (หรือปุ่มลัดที่คุณบันทึกไว้) เพื่อดูคำสั่งยุทธวิธีและปุ่มลัดที่ใช้งานอยู่ทั้งหมดขณะเล่นเกมได้อย่างรวดเร็ว *(ต้องการให้ Helldivers รันในโหมด Borderless Fullscreen หรือ Windowed)*

![หน้าต่างซ้อนทับแชทด่วน](screenshots/overlay.png)

- **รองรับภาษาของ UI หลากหลายภาษา:** รองรับ 28 ภาษา
- **สถาปัตยกรรมตัวแปลงผู้ให้บริการ:** สร้างขึ้นด้วยอินเทอร์เฟซผู้ให้บริการ AI แบบโมดูลาร์ มาพร้อมกับตัวแปลงที่ได้รับการปรับแต่งประสิทธิภาพสูงแบบไม่เสียเวลาคิด (zero-thinking) สำหรับ **Google Gemini** (`gemini-flash-lite-latest` / `gemini-2.0-flash-lite`) พร้อมสัญญาส่วนขยายผู้ให้บริการสำหรับ OpenAI, Claude และ DeepSeek (ยังไม่เปิดใช้งาน)
- **การตั้งค่าโทนการแปล:** สบายๆ (Casual): สแลงเกมภาษาพูดและศัพท์ยุทธวิธีของเกมเมอร์ / ปกติ (Normal): โทนการสนทนาที่เป็นธรรมชาติโดยไม่มีสแลงเกม
- **ปุ่มลัดหยุดชั่วคราว / ทำงานต่อส่วนกลาง:** กด `Ctrl + F10` (หรือปุ่มลัดที่คุณกำหนด) ได้ทุกเมื่อเพื่อสลับสถานะของผู้ช่วยระหว่าง **ทำงานอยู่ (Active)** และ **หยุดชั่วคราว (Paused)** การหยุดชั่วคราวจะระงับทั้งการแปลแชทในเกมและการส่งข้อความแชทด่วนอย่างสมบูรณ์
- **ปุ่มลัดเฉพาะฟังก์ชัน:**
  - **เปิด/ปิดเฉพาะการแปล:** กด `Ctrl + F11` (หรือปุ่มลัดที่คุณบันทึกไว้) เพื่อหยุดชั่วคราวหรือทำงานต่อเฉพาะการแปลแชททันทีโดยไม่ส่งผลกระทบต่อแชทด่วน (พร้อมการแจ้งเตือนป๊อปอัปบนหน้าจอ)
  - **เปิด/ปิดเฉพาะแชทด่วน:** กด `Ctrl + F12` (หรือปุ่มลัดที่คุณบันทึกไว้) เพื่อหยุดชั่วคราวหรือทำงานต่อเฉพาะข้อความแชทด่วนทันทีโดยไม่ส่งผลกระทบต่อการแปล (พร้อมการแจ้งเตือนป๊อปอัปบนหน้าจอ)

![การตั้งค่า](screenshots/settings.png)

- **การจัดเก็บข้อมูลรับรองอย่างปลอดภัย (DPAPI):** ข้อมูลที่สำคัญ เช่น โทเค็น API ของผู้ให้บริการ AI จะได้รับการเข้ารหัสขณะจัดเก็บบนดิสก์โดยใช้ Windows Data Protection API (DPAPI, ขอบเขต `CurrentUser`) ข้อมูลรับรองจะไม่ถูกเก็บเป็นข้อความธรรมดาในไฟล์คอนฟิกูเรชัน และสามารถถอดรหัสได้เฉพาะบนเครื่องของคุณผ่านบัญชี Windows ของคุณเท่านั้น
- **ปราศจากการเก็บข้อมูลการใช้งานและความเป็นส่วนตัวสมบูรณ์แบบ:** เครื่องมือนี้ไม่มีการรวบรวม บันทึก หรือส่งข้อมูลผู้ใช้หรือข้อมูลการวัดและส่งข้อมูลทางไกล (telemetry) ใดๆ ทั้งสิ้น คำขอแปลภาษาทั้งหมดจะสื่อสารโดยตรงและเฉพาะกับปลายทางของผู้ให้บริการ AI ที่คุณกำหนดค่าไว้โดยใช้ข้อมูลรับรอง API ส่วนตัวของคุณ
- **ปลอดภัย 100% โดยไม่แก้ไขไฟล์เกม:** ไม่มีการแตกไฟล์หรือแก้ไขอาร์ไคฟ์ของเกม ไฟล์เกมของคุณจะยังคงเป็นเวอร์ชันดั้งเดิม (vanilla) 100% โดยไม่มีการดัดแปลง

## 2. การติดตั้งและการตั้งค่า

### ข้อกำหนดของระบบ
หากคุณกำลังใช้งานเวอร์ชันสแตนด์อโลนที่คอมไพล์ไว้ล่วงหน้า (`HD1-Babel.exe`):
- **ระบบปฏิบัติการ:** Windows 10 / 11 64-bit (x64)
- **Desktop Runtime:** [Microsoft .NET 10 Desktop Runtime (x64)](https://aka.ms/dotnet/10.0/windowsdesktop-runtime-win-x64.exe) (ตัวติดตั้งโดยตรง)
- **เกมเป้าหมาย:** *Helldivers* (2015) บน Steam (64-bit `helldivers.exe`)

### การตั้งค่าคีย์ AI API ฟรี
- **ข้อมูลรับรองผู้ให้บริการ AI:** คีย์ API ของ Google Gemini (รับคีย์ส่วนบุคคลฟรีได้จาก [Google AI Studio](https://aistudio.google.com/) ([ดูวิดีโอแนะนำการใช้งานนี้](https://www.youtube.com/watch?v=YHFMrZD-_3g)))
- **การเชื่อมต่ออินเทอร์เน็ต:** จำเป็นสำหรับการเรียกใช้ API แปลภาษา

### การดาวน์โหลดและติดตั้ง (เวอร์ชันสำเร็จรูป)

คุณ**ไม่จำเป็น**ต้องติดตั้งเครื่องมือนักพัฒนาหรือคอมไพล์จากซอร์สโค้ดเพื่อใช้งาน Babel ([แต่หากคุณต้องการ](#4-การพัฒนา-คอมไพล์จากซอร์สโค้ด)):
1. ไปที่ส่วน **[Releases](https://github.com/difinim/helldivers1-babel/releases)** ทางด้านขวาของหน้าโครงการ GitHub
2. ภายใต้รีลีสล่าสุด ให้ขยายรายการ **Assets**
3. ดาวน์โหลดไฟล์บีบอัดสำหรับการแจกจ่ายแบบสแตนด์อโลน: **`Helldivers1Babel-v<version>-win-x64.zip`**
4. แตกไฟล์ zip ไว้ที่ใดก็ได้ในคอมพิวเตอร์ของคุณ (เช่น `C:\GamesTools\Helldivers1Babel`)
5. เปิดโฟลเดอร์และรันไฟล์ **`HD1-Babel.exe`**

> [!NOTE]
> **ข้อกำหนดเบื้องต้น:** ผู้ใช้ปลายทางต้องการเพียง [Microsoft .NET 10 Desktop Runtime (x64)](https://dotnet.microsoft.com/download/dotnet/10.0) ฟรีเท่านั้น ไม่จำเป็นต้องมีคอมไพเลอร์ C++, SDK หรือชุดเครื่องมือใดๆ ในการรันเวอร์ชันรีลีส

> [!NOTE]
> **ข้อควรทราบ:** เนื่องจาก InjectorService.cs ใช้ Windows process injection API มาตรฐาน (`VirtualAllocEx` + `WriteProcessMemory` + `CreateRemoteThread`) โปรแกรม Windows Defender หรือแอนตี้ไวรัสภายนอก_**อาจ**_ตรวจพบโดยการวิเคราะห์พฤติกรรม (heuristic detection เช่น Generic HackTool) นี่เป็นพฤติกรรมปกติของตัวฉีดม็อดเกมและสามารถเพิ่มลงในรายการที่ปลอดภัย (allowlist) ได้อย่างมั่นใจ

## 3. คู่มือการใช้งาน

### เริ่มต้นใช้งาน
1. เปิด **Helldivers 1 Babel** (`HD1-Babel.exe`)
2. ในการเปิดใช้งานครั้งแรก ให้ไปที่แท็บ **การตั้งค่า (Settings)**:
   - ป้อน **คีย์ API Google Gemini** ของคุณ (จัดเก็บอย่างปลอดภัยด้วยการเข้ารหัส Windows DPAPI)
   - เลือกภาษาเป้าหมายของคุณ (เช่น `ไทย (Thai)`)
   - คลิก **ทดสอบการเชื่อมต่อ API (Test API Connection)** เพื่อตรวจสอบคีย์และความหน่วง
   - ปรับแต่งปุ่มลัด **หยุดชั่วคราว / ทำงานต่อ (Pause / Resume)** ตามต้องการ (ค่าเริ่มต้นคือ `Ctrl + F10`)
3. กำหนดค่าคำสั่งยุทธวิธีของคุณในแท็บ **แชทด่วน (Quick Chat)** (เช่น ผูก Numpad 0-9 เข้ากับข้อความที่คุณต้องการ)
4. เปิดเกม **Helldivers** บน Steam ทาง Babel จะตรวจพบ `helldivers.exe` โดยอัตโนมัติ ฉีด `BabelHook.dll` และสร้างการเชื่อมต่อ IPC แบบ Named Pipe ความเร็วสูง

### การสื่อสารในเกมและกรณีการใช้งาน

#### 1. การแปลข้อความขาเข้าอัตโนมัติ
ข้อความขาเข้าจากเพื่อนร่วมทีมจะถูกตรวจพบและแปลเป็นภาษาเป้าหมายของคุณแบบเรียลไทม์ แสดงในแชทของเกมพร้อมชื่อและสีเดิมของผู้เล่น:
- เพื่อนร่วมทีม (English): `so quiet`
- แชทในเกม: `Diveheller: (English): เงียบจังเลยนะ`

#### 2. การตอบกลับอัตโนมัติเป็นภาษาของข้อความล่าสุด (`>>ข้อความ`)
การใส่คำนำหน้าข้อความแชทของคุณด้วย `>>` จะแปลข้อความของคุณเป็นภาษาของข้อความล่าสุดที่ได้รับจากเพื่อนร่วมทีมโดยอัตโนมัติ:
- ข้อความที่คุณพิมพ์ในแชท: `>>ใช่ เงียบเกินไปแล้ว`
- เพื่อนร่วมทีมจะเห็น: `yes, it is too quiet`

#### 3. การระบุภาษาเป้าหมายโดยตรง (`ภาษาเป้าหมาย>>ข้อความ`)
ส่งข้อความของคุณไปยังภาษาที่ระบุได้ตลอดเวลาโดยใส่คำนำหน้าเป็นชื่อภาษาตามด้วย `>>`:

| คำสั่งป้อนในแชท | ภาษาเป้าหมาย | ตัวอย่างผลลัพธ์ที่ถ่ายทอดไปยังเพื่อนร่วมทีม |
| :--- | :--- | :--- |
| `russian>>อรุณสวัสดิ์!` | Russian | `доброе утро!` |
| `english>>กับระเบิดอยู่ทางเหนือ` | English | `mines to the north` |
| `japanese>>ระวังแนวยิงด้วย!` | Japanese | `射線に注意せよ！` |
| `spanish>>ฉันต้องการกระสุน` | Spanish | `necesito munición` |
| `german>>ถอยกลับไปยังจุดอพยพ` | German | `Rückzug zum Extraktionspunkt` |
| `french>>พวกเรามาป้องกันตรงนี้กัน` | French | `défendons cette position` |

#### 4. ข้อความขาออกทั่วไปและการระงับการแปลข้อความของตนเอง
เมื่อพิมพ์ข้อความแชทในเกมตามปกติโดยไม่มี `>>` (เช่น `need ammo`, `ลุยกันเลย`) ข้อความของคุณจะถูกส่งผ่านแชทผู้เล่นหลายคนตามปกติโดยตรง เมื่อเปิดใช้งานตัวเลือก **"ไม่ต้องแปลข้อความขาออกทั่วไป"** (เปิดอยู่เป็นค่าเริ่มต้นทั้งในแถบควบคุมด่วนและการตั้งค่า) Babel จะระงับการแปลข้อความของคุณส่งกลับมาให้ตัวคุณเอง หากปิดตัวเลือกนี้ Babel จะประมวลผลข้อความในเครื่องผ่านกระบวนการแปลข้อความขาเข้าด้วยเช่นกัน

#### 5. ปุ่มลัดแชทด่วนเชิงยุทธวิธี
กดปุ่มลัดแชทด่วนที่กำหนดค่าไว้ (เช่น `NumPad 1`-`NumPad 9`) ขณะเล่นเกมเพื่อส่งข้อความที่กำหนดไว้ล่วงหน้าลงในแชทหลายคนได้ทันทีโดยไม่ต้องเปิดช่องพิมพ์แชท การกดปุ่มทั้งหมดจะส่งผ่านไปยังเกมอย่างราบรื่น ช่วยให้การควบคุมตัวละครยังคงตอบสนองได้อย่างสมบูรณ์

#### 6. หน้าต่างซ้อนทับอ้างอิงแชทด่วนเชิงยุทธวิธี (`Numpad +`)
กด `Numpad +` (หรือปุ่มลัดที่คุณบันทึกไว้ในแท็บ **แชทด่วน**) ได้ทุกเมื่อเพื่อสลับเปิด/ปิดหน้าต่างซ้อนทับอ้างอิงบนหน้าจอซึ่งแสดงรายการคำสั่งแชทด่วนที่ใช้งานอยู่ทั้งหมด หน้าต่างซ้อนทับจะจัดชิดขวาและกึ่งกลางแนวตั้งของหน้าจอ แสดงรายการคำสั่งที่เปิดใช้งานในรูปแบบ `[<ปุ่มลัด>] <ข้อความ>` (โดยข้อความจะถูกตัดทอนไม่เกิน 30 ตัวอักษร) โดยใช้รูปแบบภาพที่ไม่รบกวนสายตาเช่นเดียวกับการแจ้งเตือน Toast
> [!NOTE]
> **ข้อกำหนดโหมดการแสดงผล:** ต้องกำหนดค่า Helldivers ให้ทำงานในโหมด **Borderless Fullscreen** (หรือ Windowed) ในการตั้งค่าวิดีโอของเกม เพื่อให้หน้าต่างซ้อนทับของ Windows สามารถแสดงผลทับบนตัวเกมได้

#### 7. การหยุดชั่วคราว การทำงานต่อ และการสลับเปิด/ปิดฟังก์ชัน
- **หยุดชั่วคราว / ทำงานต่อส่วนกลาง (`Ctrl + F10`):** สวิตช์หลักที่ใช้ระงับ/ทำงานต่อทั้งการดักจับการแปลและการส่งข้อความแชทด่วนอย่างสมบูรณ์
- **เปิด/ปิดเฉพาะการแปล (`Ctrl + F11`):** สลับเปิดหรือปิดเฉพาะฟังก์ชันการแปล พร้อมการแจ้งเตือนป๊อปอัปบนหน้าจอ แชทด่วนจะยังคงทำงานตามปกติ
- **เปิด/ปิดเฉพาะแชทด่วน (`Ctrl + F12`):** สลับเปิดหรือปิดเฉพาะการส่งข้อความแชทด่วน พร้อมการแจ้งเตือนป๊อปอัปบนหน้าจอ การแปลแชทในเกมจะยังคงทำงานตามปกติ
*(สามารถปรับแต่งปุ่มลัดทั้งหมดได้ในแท็บ **การตั้งค่า** และ **แชทด่วน** โดยใช้ปุ่มบันทึกปุ่มลัด)*

#### 8. การส่งออกและการเก็บบันทึกแชทถาวร
คลิก **ส่งออกบันทึก** ในแท็บการแปลและบันทึกได้ทุกเมื่อเพื่อเลือกตำแหน่งและส่งออกประวัติการแชทของคุณ (พร้อมการประทับเวลา, ชื่อผู้เล่น, ข้อความต้นฉบับ, ข้อความแปล และความหน่วง) ไปยังเอกสาร `.txt` ข้อความแชทจะยังคงอยู่ในตารางข้ามการเปิดใช้งานแอปโดยอัตโนมัติผ่านการเขียนไฟล์ลงดิสก์แบบอะซิงโครนัส (สามารถกำหนดขีดจำกัดพื้นที่จัดเก็บได้ตั้งแต่ 0 ถึง 100 MB ในการตั้งค่า พร้อมปุ่ม **ล้างหน่วยความจำบันทึก**)

#### 9. ลิงก์ข้อความแบบโต้ตอบได้
ข้อความในแชททีมที่มี URL `http://` หรือ `https://` จะแสดงผลเป็นลิงก์ที่คลิกได้ในคอลัมน์ **ข้อความต้นฉบับ** เมื่อคลิก กล่องข้อความยืนยันจะแจ้งเตือนให้คุณตรวจสอบความน่าเชื่อถือของลิงก์ก่อนเปิดในเว็บเบราว์เซอร์เริ่มต้นของคุณ

## 4. การพัฒนา (คอมไพล์จากซอร์สโค้ด)

### ข้อกำหนดสำหรับนักพัฒนา
หากคุณต้องการคอมไพล์และบิลด์โครงการจากซอร์สโค้ด:
- **ระบบปฏิบัติการ:** Windows 10 / 11 64-bit (x64)
- **.NET 10 SDK:** [.NET 10 SDK](https://dotnet.microsoft.com/download/dotnet/10.0) (`net10.0-windows`)
- **ชุดเครื่องมือ MSYS2 MinGW64 (Clang++, GCC, Make):** [MSYS2](https://www.msys2.org/) พร้อมแพ็กเกจ `mingw-w64-x86_64-clang`, `mingw-w64-x86_64-gcc` และ `mingw-w64-x86_64-make` - จำเป็นสำหรับการคอมไพล์ไลบรารี native hook (`BabelHook.dll`) และการสร้างคอมไพเลอร์ย่อยอย่างเป็นทางการของ LuaJIT 2.0 (`vendor/luajit`) เพื่อคอมไพล์สคริปต์บูตสแตรปในเกม (`babel_bootstrap.lua`) ให้เป็นไบต์โค้ด
- **Git:** Git for Windows (พร้อม submodules แบบ recursive สำหรับ MinHook amalgamation และ LuaJIT 2.0)

### การตั้งค่าสภาพแวดล้อมอัตโนมัติ
ดับเบิลคลิก `setup.bat` (หรือรัน `setup.ps1` ใน PowerShell) ในโฟลเดอร์รากของคลังเก็บโค้ด ระบบจะตรวจสอบและติดตั้งสิ่งที่จำเป็นที่ยังขาดอยู่โดยอัตโนมัติ:
1. ตรวจสอบสภาพแวดล้อม Windows 64-bit
2. ตรวจหา .NET 10 SDK (ติดตั้งอัตโนมัติผ่าน `winget` หากยังไม่มี)
3. ตรวจหาชุดเครื่องมือ MSYS2 MinGW64 (Clang++, GCC และ Make) หากยังไม่มี จะติดตั้ง MSYS2 อัตโนมัติผ่าน `winget` และติดตั้งแพ็กเกจที่จำเป็น (`mingw-w64-x86_64-clang`, `mingw-w64-x86_64-gcc` และ `mingw-w64-x86_64-make`) ผ่าน `pacman`
4. กำหนดค่าเริ่มต้นและบิลด์คอมไพเลอร์ LuaJIT 2.0 จากซับโมดูล (`vendor/luajit`)
5. ตรวจสอบให้แน่ใจว่าได้เพิ่ม `C:\msys64\mingw64\bin` และ `C:\msys64\usr\bin` ลงใน PATH เรียบร้อยแล้ว
6. ตรวจสอบความถูกต้องของ MinHook amalgamation dependencies และรันการตรวจสอบความสมบูรณ์ของการบิลด์เบื้องต้น

### บิลด์หลักและการรวมแพ็กเกจ Release
หากต้องการล้างอาร์ทิแฟกต์ก่อนหน้า คอมไพล์เนทีฟฮุก DLL รันชุดทดสอบยูนิตทั้งหมด และรวมแพ็กเกจรีลีส:
```powershell
pwsh -File build.ps1
```
ไดเรกทอรีเอาต์พุตจะถูกแพ็กเกจไว้ใน `dist/Helldivers1Babel-vX.Y.Z/`

### ขั้นตอนการบิลด์ด้วยตนเองทีละขั้นตอน
```powershell
# 1. บิลด์เนทีฟฮุก DLL (คอมไพล์ babel_bootstrap.lua ด้วย luajit โดยอัตโนมัติ)
pwsh -File src/Babel.Hook/build.ps1

# 2. บิลด์โซลูชัน .NET 10
dotnet build Helldivers1Babel.slnx

# 3. รันชุดทดสอบอัตโนมัติ
dotnet test
```
